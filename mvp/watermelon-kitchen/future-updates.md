# 水瓜厨房：未来更新设计备忘

本文只记录已经出现、但**不进入当前 MVP 实现**的设计方向。

这些内容可以影响当前系统预留的数据边界，但不能反向要求本轮实现额外变量、公式或 UI。进入正式开发前需要重新独立设计并形成对应 Spec。

---

## 1. 植物健康度

未来可以增加独立的 Plant Health / 植株健康系统，用来表达“能活”“长得快”“长得有特色”并不是同一件事。

当前设计原则：

- 什么都吃、元素结构相对均衡的普通水瓜树，应当通常最健康；
- 这种培养方式不容易形成显著元素性状，但生长稳定、产量和恢复能力较好；
- 定向元素培养可以获得更鲜明的性状与风味，但元素结构越偏颇，植物承担的生理压力越高；
- 对普通水瓜植株进行过度单元素培养，未来可以表现为生长减速、疾病、产量下降或其他健康惩罚；
- 如果植株本身已经通过亲和 / 遗传形成某种元素适应，则它应当更容易承受对应方向的定向培养；
- 没有对应“基因”或基础亲和，却被强行推向极端元素组成的植株，可以表现得更“娇嫩”；
- 接近完全纯净的元素水瓜不应天然等于最高品质：它可能产量低、培养难、风味过于极端，但适合作为特殊加工或工业型原料。

当前 MVP 不增加：

```text
TREE_Health
Disease
Stress
Toxicity
Deficiency
```

等字段，也不设计健康度公式。

---

## 2. 与现有系统的未来接口

当前保留的：

```text
Soil
→ Tree Reserve
→ Growth
```

两层结构，为未来健康系统提供了自然接口。

未来可能观察：

- Soil 的元素组成是否长期失衡；
- Tree Reserve 是否发生某元素过度富集；
- Reserve 中是否长期缺少某些元素；
- 当前 RootPreference 是否与实际供给结构冲突；
- Growth Affinity / 遗传适应是否降低某种定向培养的压力。

这些目前都只是设计方向，不作为已确认公式。

---

## 3. 体验目标

未来健康度如果进入正式版本，应强化而不是破坏当前培养逻辑：

```text
均衡培养
→ 最稳定、最健康
→ 普通但可靠

适度定向
→ 性状鲜明
→ 仍可维持良好生长
→ 需要玩家理解元素比例

极端定向
→ 难培养、低产、脆弱
→ 得到极端风味 / 性状
→ 适合特殊用途
```

目标是让熟练玩家通过观察土壤、树体、叶片、花朵和果实表现来判断植物状态，而不是把玩法变成读取精确数值条。
