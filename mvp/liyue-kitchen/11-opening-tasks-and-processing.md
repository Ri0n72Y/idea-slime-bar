# MVP｜开局任务、果汁加工与机器维护

> 状态：2026-11-20策划记录。**当前可玩开局**与**未来NPC剧情**分开；现有生产代码及旧一果一份汁合同尚未同步。工作归属：[Work #73](https://github.com/Ri0n72Y/idea-slime-bar/issues/73)。布局由美术完成后再调整，暂不修改10号布局文档。

## 1. 当前可玩开局（无NPC剧情）

- D1开始时店铺左侧已经有**充盈的水晶球**；内部首个开放地格Soil七维总量1000V。地上已有一枚真实Seed，储藏区已有**一个普通水瓜**；右侧任务板显示两个任务。开局不需要任何NPC出现、赠物、对话或动画。
- **跨场景物品操作**：玩家可将可搬运的物品／道具拖进水晶球，落在仙境中央区域的**随机合法位置**；保留同一itemId并更新真实位置，不能直接复制、吞掉或自动使用。玩家之后可在仙境中重新整理、移动或使用物品。
- **任务一｜播种**：玩家将地上的Seed拖进水晶球，Seed遵循上述规则随机落在仙境中央可放置区域；玩家在水晶球内继续把真实Seed种入开放地格。入球落地与入土种植是不同状态；种下后任务完成。
- **任务二｜首杯果汁**：从储藏区拿取初始水瓜，使用店铺内水瓜加工/榨汁设备，装出至少一杯500ml水瓜汁，交给今天的客人；完成后更新任务板状态。水瓜普通外观、没有可视元素特征；它的隐藏七元素比例与开局种子的随机结果一致，不作为玩家当前任务内容。
- D1第一块土地已充盈，**不安排初次浇水任务**。D2起玩家早晨进入水晶球种植、浇水、巡检、维护；白天仍可加工、采摘、交单。结束今日后统一推进1d/24uh的真实生长。
- **D2任务板**：引导清洁昨天使用过的机器，并处理机器里的果壳、果肉残留。当前用任务目标文字提示，NPC演示/对话以后随剧情引入。

## 2. 一果2000ml、标准杯500ml

| 项目 | 当前设计 |
| --- | --- |
| 原料 | 一个完整水瓜 |
| 单果出汁量 | **2000ml** |
| 单杯标准容量 | **500ml** |
| 理论整杯产出 | **4杯** |
| 第一个交付目标 | 将其中**一杯**交给今天的客人 |
| 未交付果汁 | 剩余果汁/成品需保留真实库存与容量，不能随交单消失 |
| 杯子来源 | 沿用「装杯机自带容器」；不凭空添加开局散装空杯道具 |
| 用后杯子 | **后续需要清洗**；脏杯、回收与清洗方式待设备合同细化 |
| 机器残留 | 果壳、果肉留在相关机器中，次日要清洁及处理，不在加工后自动清空 |

- 这是对旧版「一果一份汁」的**明确变更**。水瓜实际产出2000ml，按500ml依次装杯，可得四杯；杯子、余量与订单交付的**体积／数量账本需要准确记录**。
- **元素性状平均继承**：拆分水瓜时，按原果**七维元素总量与组成的平均属性**赋给产出的果汁，果肉和果壳同样按此规则继承；同一批果汁分装的四杯采用统一的平均元素性状。这里的元素值用于决定风味和其他性状，不作为加工物料的可消耗守恒账户；**不要求果汁、果肉、果壳的元素数值之和等于原果**。保持七元素组成差异，精确均值字段及每杯表现由实施配置确定。
- 果壳/果肉属于真实机器残留，需有清洁及移出动作。残留作为可回收物还是废物、清理后去向、机器是否阻塞下一轮、杯子是否由客人归还，均**尚未决定**，不在本轮补造规则。
- 首果从自己的树上成熟后，也可以进入上述加工流程；D6成熟可接受，完成首次自产加工与交付是后续教程目标，不锁定D7。

## 4. 只记录的剧情设定（本阶段不实现）

- 主角初到璃月、被安排在这家店里；此前一位仙人已经尝试过培育水瓜，取得的结果不理想。
- 剧情版D1一大早，NPC送来**已充盈的水晶球**，引导玩家把种子带进仙境，在中央区域放下并种入地格；随后引导退出水晶球。
- NPC再赠送**一个与开局种子共享随机七元素比例**的水瓜。外观没有元素特征，只表现为普通水瓜；请主角借店里的水瓜榨汁机加工成水。
- NPC饮用后给出评价。评价、对话分支、剧情角色身份和具体台词以后设计，不在当前MVP引入。
- D2剧情版可由NPC引导清洁和残留物处理；目前仅任务板文字提示。
- **后续新手生态事件（只记录、不实装剧情）**：首次观察到水晶球Eco＋Soil总量低于2000V，球内几乎不再发光；NPC指出发光造成永久元素逸散，植物吸收元素用于生长、果实被采出后把其中元素带离洞天。NPC赠送一份**七元素晶核，总元素量2100V**；玩家将其作为真实道具拖入洞天并使用，把2100V外部元素转入Eco，重新亮起。七维具体分配尚未定稿，不自动推定每种300V；同一份晶核只能使用一次，之后不重复赠送。
- **触发时点待核对**：当前正常照顾、无外部补给的简化模型到第七日仍可能高于2000V，不为了将剧情塞进D1–D7而强制消耗元素或改Growth。待剧情线决定新手事件的实际时序；目前任务板版开局仍不加入NPC教学。
