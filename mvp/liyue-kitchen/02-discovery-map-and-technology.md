# 探索地图（成就图谱）与科技树 v0.1

## 1. 核心区分

**探索地图**是游戏内容的主要导航与长期目标；节点由玩家通过真实种植、培养、育种、元素反应、料理、交互发现。它包含可见条件、部分可见线索与完全隐藏的惊喜节点。

**科技树**是工具与生产能力升级：在玩家已体验流程后解锁节省重复操作的方法，或解锁更大的洞天/设备能力。技术可以依赖图谱成就与实际材料，但不能让数值提升替代探索内容。

两者分别保存进度。委托是引导途径之一，不等同于节点本身；玩家自行实验达到条件，也能发现相应节点。

## 2. 图谱展示与状态

每个节点至少拥有稳定 `id`、`title`、`category`、`prerequisites[]`、`condition`、`visibility`、`rewards[]`、`hint` 与 `completedAtDay`。

显示状态：
- `completed`：亮起，展示发现时的样本/事件证据与后继分支；
- `available`：已开放，展示明确条件；
- `hinted`：只展示名称、谜面或部分条件，可根据新线索逐步揭示；
- `unknown`：真正隐藏，完成前不显示图标/数量，以免从图位置泄露谜题；
- `locked`：已知分支但先决条件未达成，显示图谱拓扑或有限线索。

前置条件用于 **显示/解锁研究资格** 时需清晰区分与 **真实条件验证**；隐藏发现可以允许玩家先触发，之后补齐拓扑。不要强制玩家先点击成就再计算真实发现。

图谱是可缩放、多分支的静态逻辑图（作者预置节点与坐标），局内仅变更状态、连线显隐与高亮；不要求 Lua 实时计算自动布局。规模扩张靠内容数据表，不靠新 UI 控件堆积。

## 3. 初始图谱样例（初步 15 节点，需内容审查）

```
A00 一粒水瓜种子 [获得剧情种子]
 ├─ A01 洞天开垦 [完成播种]
 │   ├─ A03 第一夜 [完成第一次夜间成长结算]
 │   │   ├─ A05 新芽 [观测到 Bud]
 │   │   │   └─ A08 第一片肥厚叶 [观测到 LargeLeaf]
 │   │   │       └─ A10 花果初成 [观测到 Flower / GreenFruit]
 │   │   │           └─ A12 初次成熟 [取得合法 MatureFruit]
 │   │   └─ A06 生长的颜色 [观察到合法颜色变化]
 ├─ A02 元素的馈赠 [第一次合法收集与浇灌]
 │   ├─ A04 七色之一 [检测/记录首种元素]
 │   └─ A09 两种供给 [真实使用两种不同元素]
 └─ A07 来访者的请求 [首次接受委托]
     └─ A11 交付之日 [首次完成真实委托]

A12 初次成熟
 ├─ A13 第一杯水瓜汁 [消耗一果产生合格果汁]
 └─ A14 未知反应 [隐藏：在实果中生成合法首次反应产物]
```

节点图是探索入口，例子中的先后边只是初稿；「花果初成」要求花或青果两者之一，不能错误地把生殖阶段重置。此前没有被允许展示的七维具体值，仍不可在普通探索地图上直接公开。

后续内容可以向七元素特征、生殖与遗传、多类反应、特殊料理、仪器检测、访客故事、洞天生态、生产技艺多方向扩展。规模本身不是 P0 验收指标，优先保证每条分支具有真实可玩的行动与差异。

## 4. 节点完成的证据

领域产生标准事实事件（如 `SEED_OBTAINED`、`TREE_PLANTED`、`BALL_COLLECTED`、`ORGAN_STAGE_CHANGED`、`FRUIT_MATURED`、`REACTION_PRODUCED`、`JUICE_CREATED`、`ORDER_DELIVERED`），探索服务消费事件与当前世界状态，执行声明式条件，写入一条不可重复领取的完成记录。

必须记录关键证据 ID（`plantId/fruitId/materialId/eventId`），以便打开已完成节点查看产生发现的真实对象或当时快照。后续物品被加工/消耗后，历史发现仍保留。

不要为图谱建立另一套 Growth 或元素反应解释计算。只有已知事实事件可以完成数字与物质类成就。

## 5. 科技树：根据重复劳动逐步开放

第一批技术候选：
- **收集袋**：真实累计多次手动收集后，允许一次选择多个元素球；减少重复点击。
- **浇灌预设**：玩家自己完成数次地块浇灌后，可以将选定元素来源与地块保存为一条顺序操作。
- **简易批处理架**：有了多次实际榨汁/料理经验后，允许对多份材料执行同一合法配方；所有原料仍逐份消耗。
- **凝聚增幅**（P1）：提高每天 N 次凝聚次数；最好与收集便捷性同步开放，避免技术升级增加操作负担。
- **洞天扩展、夜间自动化生产**（P1 以后）：增加可管理地块和设备；每晚采用同一领域计算与物质守恒。

研发消耗可以是材料、特定样本、委托奖励或成就条件；初期不引入独立且需要长时间刷取的科研货币。技术解锁后永久保留，不要求每天重复付款/充电才能使用基础便捷操作。

## 6. 需要设计的内容生产模板

每个探索节点在实施前填写：
`起点线索 → 玩家可执行动作 → 真实判定条件 → 可观察反馈 → 完成证据 → 后续分支/奖励`。

每项科技填写：
`过去至少经历的手工操作 → 当前重复成本 → 技术所需发现与材料 → 操作节约量 → 不改变的领域规则`。

避免只新增称号或图标、不新增实际知识和操作途径的内容填充。
