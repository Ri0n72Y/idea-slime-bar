# 洞天仙力与地格扩展 v0.5（设计草案）

## 1. 名称及与原神官方设定的边界

**官方简体中文名：「洞天仙力」。** 米哈游《原神》1.5 版本「玉扉绕尘歌」更新说明（https://www.hoyolab.com/article/328446）写明：放置摆设提升「洞天仙力」，提升仙力等阶可增加洞天产出；「信任等阶」由首次制作摆设获得信任度提升；「洞天宝钱」是可与壶灵交换道具/摆设/图纸的货币。

璃月厨房沿用**洞天仙力**这一已确认官方中文名，但为适配单机探索经营玩法，将它设计成**可取得、可消费的一种统一资源**；因此此处的「花费洞天仙力解锁能力」是璃月厨房自身的玩法，不冒充原神尘歌壶官方结算规则。MVP 不再另造洞天宝钱、信任等级或第二种科研点数。

## 2. 来源与事件守卫

玩家在白天完成有意义的互动和劳动时获得洞天仙力：
- **访客互动**：首次完成对话事件、提交真实剧情物品、发现线索/达成互动事件；同一对话重复打开不得反复领取。日常无后果的点击不给仙力。
- **委托交付**：按实际订单 ID 与物品 ID 完成完整水瓜或杯装果汁限时委托；可以依数量、难度、品质和剩余期限设计不同一次性奖励。每张订单最多奖励一次，过期不领奖。
- **种植/采摘**：成功建立并至少经历一次真实夜间生长的有效种植周期可奖励仙力；采摘真实成熟果可奖励小额仙力。禁止种下立刻铲掉重种无限刷取。每次采摘使用独立 fruitId 校验，不能重复点击领奖。

建议遵循 **首次发现 > 完成委托 > 日常种植/采摘** 的价值排序，但实际数额须与 K/N、首果时长、订单期限联合测算。探索节点可赠送一次性的仙力奖励，但它应属于真实发现的完成事件，防止多个页面重复结算。

**最小守卫**：每个可获奖事件有稳定 `eventId` 与来源 `sourceId`（visitorEventId / orderId / plotId + cycleId / fruitId / discoveryId）；奖励总账记 `rewardedIds`，一个来源只入账一次。不能通过刷新页面、重新打开聊天或夜间重算重复获得。

## 3. 收支与解锁

唯一可消费资源：
- `adeptalEnergy.balance` 当前剩余仙力，所有建造/技术消费先检查再扣除，绝不为负。
- `adeptalEnergy.earnedTotal` 历史累计获得仙力，便于里程碑/统计，不因消费减少。
- `adeptalEnergy.spentTotal` 历史累计花费；保证 `earnedTotal - spentTotal = balance`（除明确的一次性开局资助外，开局资助也记录为获得事件）。
- `rewardedIds` 去重记录。技术与地格永久解锁，已花费的仙力不因过期订单、采摘树木或库存改变而回退。

消费范围：
1. **地格扩建**：在七格水晶球内部逐步开放尚锁定的外围蜂巢地块，能够播种/浇灌/生长。初始建议只开放中央一格，外围六格全部可见并呈休眠状态（此数值是体验候选，需要按首果与订单校准）；七格就是 MVP 最大地格数，不需要动态生成第八格。
2. **工具升级**：批量收集、快速分配浇灌、仓储整理、批量剥壳/装杯等，需玩家有过相应操作经验或探索节点。
3. **额外能力**：提高每日 N 次元素凝聚额度、自动浇灌、批次生产管理等，须定义真实能力并经过 Gate；不直接乘 Growth 或修改根系/反应公式。

建造消耗和技术消耗调用同一 `spendEnergy(amount, unlockKey)` 验证并原子记录，不能通过多次点击同一解锁控件重复扣费。

## 4. 七格状态与显示

```text
             ② 休眠
       ⑦ 休眠      ③ 休眠
             ① 已开放
       ⑥ 休眠      ④ 休眠
             ⑤ 休眠
```

- 球内固定七个地格，`plotId=1..7`，中心1号；`plot.unlocked` 决定能否种植。
- 锁定格可见六边形轮廓和解锁消耗，在点击时提示「消耗 X 洞天仙力开垦」，不允许偷偷接收土壤、养分或 plant。
- 已开放格每格仍然独立遵守原有 Soil、Reserve、Tree 生长账本。额外地格提高种植规模；每日凝聚 N 是**全洞天总数**，不会因购买地格自动乘七。
- 洞天**地面临时存物**与种植地格占用分离；锁定格区域不开放种植，不以地面临时摆放绕过开垦。
- 七格解锁建议逐步涨价，但不先写死成本或日均收入；首格解锁后必须验证日常仙力可支付下一格，并验证额外格确实能够获得合理的元素输入。

## 5. 与探索/订单/科技节奏结合

- **开局种子直接存在物品栏**，与访客事件无关；中央格为初期建议开放格。首批仙力来源于有效种植、采摘、订单交付与实际探索发现；访客互动奖励在 U9 最后接入。
- 玩家连续完成种植与采摘、按时交付早期水瓜订单，积累首批足以解锁第二格的仙力。
- 第二格扩大操作空间后，通过新委托/隐藏发现引出提高 N、批量浇水等便利技术；避免先给大面积耕地再迫使玩家做大量相同点击。
- 对于每个可升级能力，要求已有操作经历或探索条件（qualifier）+ 仙力费用（cost）。**资格由图谱/经历证明，费用由洞天仙力承担**。
- 不强制玩家只能走「先升级地格再研究」路线；至少提供一条可选的便利工具，使玩家可自主选择支出顺序。关键主线不可因错花资源永久卡死。
- 若限时订单失败，种植、采摘、有效互动仍能获得仙力；后续订单能重新提供收入。绝不让过期单剥夺唯一的地格/工具解锁来源。

## 6. P0 最小验收

- 官方用词在 UI 和 docs 一致，明确这是游戏内重设计的可消费仙力。
- 初期真实种植周期、成熟果采摘与水瓜/果汁订单交付能入账，重复事件不重奖；最后接入访客一次性交互奖励，复用同一去重守卫。
- 界面可见当前余额和地格购买消耗、七格解锁状态。
- 消耗仙力解锁至少一块外围格，并能在新格种树及进行独立夜间结算。
- 至少一项技术或额外能力能通过 `满足探索/劳动条件 + 支付仙力` 解锁并真实生效。
- 存档持久化状态待千星 Lua 实机证实；至少本地会话内不能通过切换 UI/重载相同逻辑造成重复领取。

## 7. 待定校准

需要真实模拟决定：初始可用格数（建议1）、每晚 K uh、每日 N 次凝聚、首果天数分布、种植/采摘单次奖励、交单奖励、首二格价格、第一项科技价格和首单截止日。新能力只改每日供给或操作效率时仍需实测对七格规模及订单压力的影响。
