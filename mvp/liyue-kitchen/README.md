# 璃月厨房：还得自己种 — 独立 MVP v0.1（设计草案）

> 状态：玩法与界面重构草案，供 Lead 审查。尚未批准替代原有参赛范围、尚未实现。
> 平台：原神·千星奇域；本地 Lua 单机。暂定英文名 Liyue Kitchen: Grow It Yourself。

## 核心定位

玩家坐在璃月厨房的柜台后，接待璃月仙人及偶尔造访的普通人，接收委托、材料和线索；通过桌面上的洞天管理终端操纵尘歌壶洞天，种植具有七元素亲和的水瓜，并在工作台上取样、剥壳、榨汁、烹饪、交付。

**主线：发现 → 验证 → 完成探索节点 → 解锁更广阔的发现范围。**
研究新技术主要用来减少已掌握流程的重复劳动，扩展规模和加速后期体验。客人提供线索及动机，订单不是必须赚钱的生存任务。

## 四项设计支柱

1. **固定柜台与实体操作**：借鉴《Probably Stolen》的柜台/物品/设备空间和《Papers, Please》的访客/资料/规则检查操作；不照搬两者经济惩罚。
2. **昼夜分离**：白天无限时交互、手动结束一天；夜间统一按既有 uh 数值结算生长与生产，次晨给出可核验的变化报告。
3. **探索地图即核心内容**：可见、有线索和隐藏的成就以依赖关系构成可缩放图谱；种植、育种、元素反应、加工、料理、交互均为发现渠道。
4. **在重复开始乏味时引入科技**：通过已经体验过的工作及发现解锁工具、批量操作、流程保存、自动化和可扩展的产能；避免用新的自动化代替尚未经历的探索。

## 背景及舞台

一只尘歌壶提供可扩展的种植洞天。厨房柜台接待仙人、居民和携带特殊物品的访客。人物身份、故事和任务均服务于探索；无租金、生存倒计时、强制营业额和破产条件。世界观使用原神璃月/仙家洞天设定，视觉以璃月机关法器表达洞天终端，交互保留电脑窗口习惯。

## 核心循环

- **早晨**：展示上一夜生产报告（植株阶段变化、异常、成熟、库存及设备完工）；刷新当日访客、免费凝聚次数、探索线索。
- **白天**：处理访客/订单；凝聚有限次数随机纯元素球，收集并分配至选定地块；布置洞天、播种/移栽、取样、整理材料；剥壳、榨汁、料理、交付；查看探索地图与科技树。
- **结束今日**：玩家显式点击结算。依次执行既有土壤→吸收→生长→反应→收获/设备时间进度；累计指定 uh，生成只读日结报告，跨入次晨。
- **持续推进**：发现记录自动匹配真实事件；图谱解锁更复杂的线索、委托和物品用途；科技升级让重复操作更简便。

## 对现有规则的保护

现有七维 V/G 账本、RootPreference/Affinity、生长与遗传、元素反应、显色和感官合同继续作为唯一事实来源（见 `../aquamelon-kitchen/`）；**不以新的游戏日重写 Growth 阈值、反应消耗或概率**。原版每 10 秒推进 1uh 是旧版实时节奏映射，新版由结束一天调用 `advanceUH(K)` 实现；`K=24` 作为需要数值验算的初始候选，而非已通过校准的定值。

现有单果一汁仅为旧版快捷加工路径。新 MVP 需要在独立的材料加工合同中定义果实/果肉/果壳/果汁/料理的消耗与产出，严禁同一物质账本复制到多份产物，具体产率另审。
