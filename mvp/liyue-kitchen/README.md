# 璃月厨房：还得自己种 — 独立 MVP v0.5（设计草案）

> 状态：玩法与界面重构草案，供 Lead 审查。尚未批准替代原有参赛范围、尚未实现。
> 平台：原神·千星奇域；本地 Lua 单机。暂定英文名 Liyue Kitchen: Grow It Yourself。

## 核心定位

玩家坐在璃月厨房的柜台后，接待璃月仙人及偶尔造访的普通人，接收委托、材料和线索；操作一只透明洞天水晶球：球内固定七个可见蜂巢地块（中心一格、周围六格），初始仅部分地格开放，玩家消耗洞天仙力逐步开垦；已开放地格各可种植一棵具有七元素亲和的水瓜树；玩家在水晶球下方仓储区及左右加工区完成剥壳、榨汁、装杯与订单交付。

**主线：发现 → 验证 → 完成探索节点 → 解锁更广阔的发现范围。**
研究新技术主要用来减少已掌握流程的重复劳动，扩展规模和加速后期体验。访客提供线索及动机。**限时水瓜/果汁委托**承担前期生产驱动力，失约失去该单奖励但不永久阻断探索主线。与客人有效互动、完成订单、真实种植周期和成熟采摘都能获得**洞天仙力**，用于地格开垦、工具升级和额外能力。

## 四项设计支柱

1. **固定柜台与实体操作**：借鉴《Probably Stolen》的柜台/物品/设备空间和《Papers, Please》的访客/资料/规则检查操作；不照搬两者经济惩罚。
2. **昼夜分离**：白天无限时交互、手动结束一天；夜间统一按既有 uh 数值结算生长与生产，次晨给出可核验的变化报告。
3. **探索地图即核心内容**：可见、有线索和隐藏的成就以依赖关系构成可缩放图谱；种植、育种、元素反应、加工、料理、交互均为发现渠道。
4. **在重复开始乏味时引入科技**：通过已经体验过的工作及发现解锁工具、批量操作、流程保存、自动化和可扩展的产能；避免用新的自动化代替尚未经历的探索。

## 背景及舞台

一只尘歌壶提供可扩展的种植洞天。厨房柜台接待仙人、居民和携带特殊物品的访客。人物身份、故事和任务均服务于探索；无租金、破产条件。订单有明确游戏日截止日期，鼓励玩家安排夜间生产；世界观使用原神璃月/仙家洞天设定，**洞天可视化主体是一只水晶球**，交互保留电脑工作台的鼠标操作习惯。

## 核心循环

- **开局**：新建游戏时物品栏直接生成一枚真实水瓜种子（有独立 itemId），不用和访客交谈。玩家从物品栏拖拽种子到已开放的洞天格地播种。
- **早晨**：展示上一夜生产报告（植株阶段变化、异常、成熟、库存及设备完工）；刷新当日凝聚次数、订单与探索线索。访客互动在最后一个 UI 开发阶段接入。
- **白天**：通过右侧委托板接单和交单；每天凝聚 N 次随机纯元素球，分配到**已开垦地格**；拖拽种子播种、收获、将物品临时丢在洞天地面或存入球下仓储区；在左右工作区剥壳、榨汁、装杯；通过洞天仙力解锁地格/工具/能力，查看探索地图与科技树。访客提供任务、来物与额外仙力的交互放在最后。
- **结束今日**：玩家显式点击结算。按既有土壤→吸收→生长→反应规则推进 K uh，结算未来可能出现的夜间设备进度；更新委托剩余天数/过期状态，生成只读日结报告，跨入次晨。**首版剥壳、榨汁、装杯为白天手动操作**。
- **持续推进**：发现记录自动匹配真实事件；图谱解锁更复杂的线索、委托和物品用途；科技升级让重复操作更简便。

## 对现有规则的保护

现有七维 V/G 账本、RootPreference/Affinity、生长与遗传、元素反应、显色和感官合同继续作为唯一事实来源（见 `../aquamelon-kitchen/`）；**不以新的游戏日重写 Growth 阈值、反应消耗或概率**。原版每 10 秒推进 1uh 是旧版实时节奏映射，新版由结束一天调用 `advanceUH(K)` 实现；`K=24` 作为需要数值验算的初始候选，而非已通过校准的定值。

现有一果一汁仍为产出数量合同；新增显式的 **完整水瓜→剥壳→果肉→榨汁→未装杯果汁→装杯果汁** 实物链。七维 E_free/Products 从原果完整传至果肉、果汁和杯装果汁，前态逐步消耗，果壳暂作无 G 载荷的物理副产物；该最小分账提案待 Lead 批准。原果直接交付水瓜订单。煮锅、研钵、复杂料理均在后续版本。

## UI-driven 开发原则

本版以实际 UI 对象和玩家操作为实施入口，采用「看见对象→点击/操作→Lua 领域状态真实变化→画面反馈→千星编辑器实机验收」的小型垂直切片。**开发任务与进度按 UI-00～UI-10 可玩清单追踪**，禁止仅以纯逻辑模块、静态原型截图或占位按钮宣称功能完成。UI-00 先建立主屏；**UI-01（U1）验证开局物品栏内真实种子**；**UI-02（U2）验证将种子拖放进开放地格播种**；再接入元素/昼夜、生长/收获、加工、订单、仙力和探索地图；**UI-10 最后实施访客**。真实拖拽是 U2 验收条件，选择后点击地块不能代替。完整入口：[05-ui-driven-implementation.md](05-ui-driven-implementation.md)。
