# 璃月厨房 — UI-driven 实施与验收

**唯一当前技术路线**：React + TypeScript + Vite + PixiJS 8。先完成 Web 版，Tauri v2 打包延期。此表定义目标，不代表已通过验收。

## 验收规则

每个切片须完成 **玩家可见对象 → 真实鼠标/触摸操作 → 领域合法状态变化 → 成功/拒绝反馈 → 浏览器可复现证据**。同一对象只由一个渲染系统处理输入与命中。Playwright 覆盖真实 UI 操作及截图，领域状态/事件记录用于核对。未验证不标记完成。

## U1：16:9 固定主界面和七格交互

- [ ] 在 `packages/liyue-kitchen/` 建立独立 Web 应用及纯 TypeScript 领域骨架，不复用其他原型的 UI 或旧脚本。
- [ ] React 实现顶部日期/仙力/结束今日、左侧访客预留、右侧委托/探索和底部物品栏/仓储/加工工作区；区域边框清晰、文字对比度足够。
- [ ] PixiJS 绘制中心水晶球、七个稳定 `plotId=P01..P07` 的六边形，初期 P01 开放，其余六格锁定；显示独立可用/不可用及选中效果。
- [ ] P01 指针/触摸选中与取消、P02～P07 锁定拒绝、状态反馈与禁用区域无副作用；不可制造虚假订单或材料。
- [ ] PC 16:9 和移动设备横屏布局完整，无遮挡、溢出、误触；实际浏览器操作及截图证据归档。**U1 需重新实施，不沿用其他平台的完成状态。**

## U2：初始种子、真实拖放、元素与昼夜生长

- [ ] `newGame` 一次生成唯一 `Seed`（稳定 itemId），读档和重复渲染不重复发放。
- [ ] 从物品栏通过指针拖动种子到合法开放地格，松开后唯一种子消耗、目标格产生 plantId；非法放下、取消、重复 Drop 均不消耗。
- [ ] 每日 N 次随机纯元素球（每枚 50V）、收集和浇灌，投给对应 Soil；共享额度不随地格倍增。
- [ ] 显式结束今日推进 K uh，结算真实 Growth/反应，次晨显示阶段变化及 N 次数重置；可重放数值事件。
- [ ] **一个切片同时验收**：拖拽播种、元素供给和跨日生长；鼠标/触摸输入均要验证，不以点击代替拖放。

## U3～U9

- **U3 采摘和仓储**：成熟后产生唯一果物，水晶球地面/物品栏/仓储位置移动不复制 ID；未熟不得采摘。
- **U4 剥壳、榨汁、装杯**：消耗前态、创建后态，七维物质账本连续；材料不足和重复操作拒绝。
- **U5 限时委托**：右侧委托板发布完整水瓜与杯装果汁订单；真实库存扣减、按游戏日截止与奖励去重，不依赖访客。
- **U6 洞天仙力**：有效劳动/订单/发现入账，消费开垦外围一格；新地格拥有独立 Soil/Plant。
- **U7 探索与科技**：真实事件点亮探索节点，完成一种省力科技，升级条件与仙力成本均生效。
- **U8 核心闭环**：无访客条件下从开局种子、播种、成长、采摘、加工、交单、开垦到发现的完整浏览器可玩流程。
- **U9 访客**：最后加入立绘、对话、来物、任务线索与仙力互动，复用现有物品/订单/探索状态，不能重复发放开局种子。

## 阶段完成标准

- 可重复的浏览器操作记录与截图，必要时附视频；明确源码版本、设备尺寸、通过项和未验证项。
- 合法及非法输入分别核对真实 `GameState`、稳定 ID、物质/奖励守卫。领域测试验证规则，Playwright 验证真实交互。
- 独立 Reviewer 审查准确 PR HEAD 及验证证据；Lead 决定合并及进入下一阶段。
- 业务代码只进入《璃月厨房》专用工作区；不要将旧工程脚本、模拟器探针或测试素材作为正式产品代码。
