# 璃月厨房 — UI-driven 开发清单 v0.5

> 单机千星 Lua，沿用现有水瓜 V/G、生长、亲和、反应数值合同。开发与验收按照玩家可见 UI 和真实交互顺序组织。**访客系统放在最后一个切片 UI-10**，开局种子直接属于玩家物品栏。U1/U2 分别对应下方 UI-01/UI-02。
>
> 状态：设计执行清单，所有实机项默认未验证；没有千星实际交互证据不得打勾。

## 1. 执行约定

1. 每个切片按照「屏幕上看到对象 → 玩家输入 → 唯一 Lua Game 状态变化 → 画面反馈 → 异常输入和实机验收」实现；不要先实现全部逻辑再做 UI。
2. 16:9 主屏：访客位置预留（前期不需要对话/角色脚本）、中央七格水晶球、球下仓储/初始物品栏、左右工作区、右侧委托与探索、顶部日期/仙力/结束今日。未开放操作不得做虚假可用按钮。
3. **UI-01（U1）只验收初始种子在物品栏中真实存在**；不要求访客开场或获取种子动作。新游戏初始化一次 `Seed` 物件（独立 `itemId`），读取/回到场景不重复生成。
4. **UI-02（U2）专门验证鼠标拖拽种子到可用地格播种**。必须实际捕获拖拽开始、移动、落点命中并触发合法领域播种，种子从物品栏消耗、地块出现真实 Seed。没有拖拽实机证据不能标记 UI-02 Done。「选中→点击」仅为可能的临时诊断手段，**不能替代本阶段的验收条件**；若千星 UI API 不支持完整拖放，标记 Blocked，记录 API/编辑器限制与下一步最小技术验证。
5. 访客功能置后：**前期订单由右侧委托板直接发布**，由真实 `orders` 领域逻辑驱动并按日结算；不得添加假访客对象或依赖与 NPC 说话的状态。UI-10 完成后才把真实访客展示/递交/对话事件与既有订单域绑定；订单规则不必重写。
6. 开局种子的发现由 **首次获得/开局初始化该真实物件**的事件完成，后续播种节点由播种事件完成。访客节点在 UI-10 才加入，不得成为前期种植、订单、仙力或科研科技的必要前置。
7. 原有物品/生长/夜间/反应/仙力账本只有一份真值；Lua UI 为投影与合法操作入口。静态编辑器资源的布局、图片/ID 绑定需要在千星编辑器内完成。
8. Done 必须有实际千星运行截图/录屏、操作序列、成功/失败画面、Lua 状态/事件证据和人工绑定清单，且单一切片可以由另一人复测。

## 2. 主要 UI 对象与行为合同

| UI 绑定键（建议） | 可见表现与操作 | 真实 Game 合同 |
| --- | --- | --- |
| `LK_C_Inventory`, `LK_C_SeedItem` | 开局物品栏显示唯一水瓜种子，鼠标按下开始拖拽 | `Game.items[seedId]` 在新游戏创建一次，kind=Seed、location=inventory；恢复/重绘不增殖 |
| `LK_C_CrystalBall`, `LK_C_Plot01..07` | 中央七格蜂巢，中心或已开垦格可作为种子拖放目标；锁定格显示条件 | `Game.plots[id].unlocked/plant`，一格一树；拖放判定 id 而非图像槽号 |
| `LK_C_DragGhost`（如需） | 按下/移动/松开鼠标时反馈拖动物体，合法目标高亮、非法目标取消 | DragStart(seedId) → DragMove(x,y) → Drop(targetPlotId) → guard + `Plant(seedId,plotId)`；失败不消费 |
| `LK_B_Condense`, `LK_C_Balls` | 每天 N 次凝聚，选择元素球浇灌 | 全洞天 N，共用额度；随机纯元素50V球，投到已开垦格 Soil |
| `LK_C_Day`, `LK_B_EndDay` | 结束今日，次晨报告和阶段变化 | 仅夜间推进 K uh，事件与订单日界不重算 |
| `LK_C_Ground`, `LK_C_Storage` | 水晶球地面/仓储展示、拾起和转移真实物品 | 相同 itemId 在不同容器中移动而非复制 |
| `LK_C_ShellStation`, `LK_C_Juicer`, `LK_C_CupStation` | 剥壳、榨汁、装杯，显示材料和缺料提示 | 成品唯一物质账本，前态消耗、下态生成 |
| `LK_C_OrderPanel`, `LK_B_Deliver` | 右侧板展示水瓜/杯装果汁、截止天数和奖励，接受/提交 | 订单在前期直接由板发布，真实日结/交付/奖励；不依赖访客 |
| `LK_C_AdeptalEnergy`, `LK_B_Unlock` | 显示仙力余额、地格开垦价和省力科技 | 实际收入去重、原子消费、永久解锁 |
| `LK_C_Discovery` | 节点/解锁线索/历史结果 | 真实事件驱动发现；开局种子由 init 事件、实际种植由 Plant 事件 |
| `LK_C_Visitor`, `LK_B_Talk` | **仅 UI-10 实现** 访客立绘、对话、递交物品、订单互动 | 访客事件可提供新增物品/订单/仙力，但不重复开局种子或覆盖既有订单状态 |

## 3. 按 UI 顺序的开发与验收清单

### UI-00：固定场景和交互底座

- [ ] 千星 16:9 主屏可见水晶球（七格）、物品栏、仓储、左右加工区、右侧委托/探索、日期/仙力及结束今日入口；访客位预留但交互隐藏。
- [ ] 七格可区分开放和锁定状态，当前测试阶段中心格可投放；其他锁定格依既定扩建合同处理。
- [ ] 实际千星鼠标点击能响应至少一个界面对象，具备选择/禁用反馈。
- [ ] **证据**：实机截图、短录屏、控件命名/绑定清单；该阶段不宣称完成种植。

### UI-01（U1）：开局种子已在物品栏

- [ ] 新建游戏时 `Game.items` 真实生成**一枚**水瓜种子，有稳定 itemId，location=inventory。
- [ ] 物品栏以真实数据绘制种子图标/数量与选中反馈，点击能看到它的合法物品身份。
- [ ] 重绘 UI、重进此画面、重复初始化入口不会获得第二枚种子；创建逻辑与「新游戏」绑定，未来读档不得再次补发。
- [ ] **证据**：新游戏开场看到种子，点击种子显示物品信息，重复进入仍仅一枚；无需任何访客事件。

### UI-02（U2）：拖拽种子进入开放地格

- [ ] 在千星实机从物品栏按住种子开始拖动，鼠标移动时有拖拽中反馈，落在开放地格能识别正确 plotId。
- [ ] 松开在合法空地格时调用 `Plant(seedId,plotId)`，原种子 itemId 从 inventory 消耗，目标地格出现真实 Seed 状态并发出可复核播种事件。
- [ ] 松开在锁定地格、已种植地格、球外、工作区或空白处时不消费种子；返回原槽位/保持原位置且显示拒绝原因。
- [ ] 双击、快速拖放和重复 Drop 不得把一枚种子种成多棵树；操作/动画以领域成功回执为准。
- [ ] **证据**：完整按住→移动→松开播种录屏，成功/失败落点截图，Game 中单一 seedId 消失且唯一 plantId 出现在目标 plotId；仅靠「点物品再点地格」不算通过。

### UI-03：凝聚浇灌、结束今日与夜间生长

- [ ] 每日可见 N 次随机纯元素球（单枚50V），选择球并对已开放地格浇灌。
- [ ] 手动结束日推进 K uh，按批准的 Soil/Reserve/Growth/反应结算；次晨日期和真实阶段变化可见，N 重置。
- [ ] 关闭/重开窗口和重复结算不会制造第二次成长；跨模型日离散事件正确去重。
- [ ] **证据**：连续多日真实浇灌、生长和 Debug 账本；K/N 为未定时清楚标注校准配置。

### UI-04：采摘、洞天地面和仓储

- [ ] 真实成熟果可采摘成独立物品，未熟果不能领取。
- [ ] 可把果实/材料放在水晶球地面或球下仓储，再拾起转移；每次真实 itemId 不变。
- [ ] 跨天/切窗物品不凭空增殖或消失，地面存物不占树位。
- [ ] **证据**：采摘和跨容器转移录屏，唯一果物物质账本可追踪。

### UI-05：剥壳、榨汁与装杯

- [ ] 实机剥壳：完整水瓜消耗，生成果肉和果壳；果肉保留唯一可食物质账本。
- [ ] 实机榨汁：果肉消耗成唯一原汁；装杯消耗原汁及空杯成真实杯装果汁。
- [ ] 缺原料、重复加工、错误类型均拒绝，不能复制 `E_free[7]` 或 `Products[]`。
- [ ] **证据**：从真实采摘果实到杯装果汁的连续录屏和物质账本；加工分配规则须事先批准。

### UI-06：右侧限时订单板（无访客依赖）

- [ ] 右侧可显示/领取真实 `orders` 对象；前期由游戏日或探索进度发布水瓜/杯装果汁订单。
- [ ] 玩家交付真实对应物品，订单完成、库存扣除与奖励只结算一次。
- [ ] 截止 D 天白天仍可交付，结束 D 天后才过期；失败不永久卡死主线。
- [ ] **证据**：两个种类各一次成功及到期/错误物品/重复交付测试；无需 NPC 出现或递单。

### UI-07：洞天仙力与开垦第二格

- [ ] 有效种植周期、成熟采摘、按时订单与真实发现获得仙力，重复事件不重复发放；访客仙力留到 UI-10。
- [ ] 购买锁定外围格，余额不足拒绝；支付后永久开放并可进行真实播种、浇灌及夜间成长。
- [ ] 第二格与第一格独立持有 Soil/Reserve/Tree，N 是全洞天共享额度。
- [ ] **证据**：通过正常劳动获得足够仙力开第二格，两格同时真实运行；重复购买不重复扣费。

### UI-08：探索地图与一项省力科技

- [ ] 种子开局持有、播种、生长、成熟、加工、交单和合法反应可以分别触发相应节点；隐藏节点不提前曝光。
- [ ] 历史证据与真实 eventId/itemId 关联，物品消耗后仍可查询。
- [ ] 重复收集后可以花仙力获得真实有效的省力工具，并复测其实际减少点击次数。
- [ ] **证据**：无需访客触发即能发现节点、完成隐藏反应与一项省力技术。

### UI-09：无人访客依赖的完整可玩闭环

- [ ] 无 Debug 指令，开局已有种子 → **拖拽播种** → N 次凝聚浇灌 → 多晚生长 → 采摘 → 完整水瓜订单 → 剥壳榨汁装杯 → 果汁订单 → 仙力开垦 → 探索/科技。
- [ ] 测试不同元素随机序列下 K/N、首果时间、订单可完成率、仙力收入、扩格节奏和重复点击量。
- [ ] 订单、唯一物品、事件/奖励、夜间结算、地格锁定的异常操作均验收，存档真实能力单独记录。
- [ ] **证据**：千星实机完整流程录屏和事件/物质账本；这一阶段为无访客核心游戏验收。

### UI-10：最后接入访客与剧情交互

- [ ] 左上访客位真正显示 NPC 立绘/对话/来物，能通过点击推进、完成有效互动并获得一次性剧情事件或仙力。
- [ ] NPC 给予任务时写入同一个 `orders` 状态，右侧委托板立即显示；订单依旧使用已有日界/交付/奖励逻辑。
- [ ] NPC 递交**额外的**合法物品时进入实际库存，不能再发初始那颗种子；重复对话不能刷种子、仙力或订单。
- [ ] 探索地图追加访客类成就与线索，不将先前核心发现回溯改成必须先与 NPC 交谈。
- [ ] **最终验收**：真实访客互动→右侧订单→生产→交付→仙力/发现，同时验证开局无访客也可完成完整生产循环。

## 4. 切片完成定义与编辑器约束

- **Done**：实际编辑器对象存在；玩家通过指定操作（UI-02 必须是拖拽）触发；Lua 中发生合法且唯一的状态变化；可见反馈明确；错误操作无副作用；具备可复测的截图/录屏与编辑器绑定清单。
- **Blocked**：真正拖放、动态图层、图谱缩放或存档缺少平台实机证据时明确记录 API 需求和试验结果；不得把替代交互标记为拖拽完成。
- 每个开发任务记录 `UI 元素 / 玩家输入 / Game 操作 / 成功反馈 / 拒绝反馈 / 实机证据 / 依赖`；优先小的玩家行为切片。
- 静态布局/素材由千星编辑器布置，单机 Lua 唯一控制真实世界状态。已有水瓜数值公式不随 UI 开发顺序改变。
