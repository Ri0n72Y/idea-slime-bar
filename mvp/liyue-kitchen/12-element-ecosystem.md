# MVP｜水晶球七元素生态与凝聚供给

> 状态：2026-11-20**概念数值基线**，不改变当前成熟的根吸收、Reserve、Growth、亲和及器官阈值公式。此文档记录生态储量、元素来源与环境反馈方向；尚未定义天气、美术色彩、元素失衡的具体阈值和完整生成算法。实施归属见[Work #73](https://github.com/Ri0n72Y/idea-slime-bar/issues/73)。

## 1. 水晶球内的七元素总量

- 水晶球是具有自身生态环境的仙境，七元素既存在于**Soil[7]**，也存在于球内**生态储量Eco[7]**，还可能暂时存在于已凝聚的元素球、玩家持有量和植物Reserve／Growth中。所有元素按七维分别记录，不能直接合成无属性V。
- **生态总量容量参考10000V（候选）**，不同于Soil[7]的合计容量**1000V**。开局状态参考：**Soil合计1000V + 其余生态储量合计3500V = 已分配4500V**；10000V是容量参考，不表示开局已有10000V或另有5500V可免费提取。
- 初始七维组成由开局种子确定的随机比例决定；开局的普通水瓜沿用同一随机比例，但不显示元素特征。这是世界初始条件，也为未来仙人此前尝试培育水瓜的剧情留依据。该随机比例如何约束每种元素下限尚未定稿。
- **元素球从生态储量凝聚**：按元素实际可用储量转出V形成球，生态储量减少对应V；收集只改变持有位置，向Soil浇灌再转入Soil。每枚球同一时刻仅有一个实际持有位置。元素越多，通常越容易凝聚成相应元素的球；完整权重函数待设计。

## 2. 蒸发、回流和真正的逸散

- 原土壤每天保留率仍为**80%/d**。这里「流失」指从Soil扣除、**尚未被根系吸收**的自然蒸发量，不能把已进入植物Reserve/Growth的养分再次当作蒸发回收。
- 对每个元素的自然蒸发量 `Evap_i`：**80%进入Eco[i]，20%从球体以光晕、粒子形式逸散并永久退出系统**。这是流失物的80/20分配，不表示整块土壤每天损失80%。
- **当日未收集的元素球，到次晨全部消失**：按其当时尚余的真实元素V逐维结算，80%回Eco、20%逸散。未收集的球不能在D2重复领取。球具体衰减、夜间过期与回流记账需在新领域合同里防止二次扣除。
- 例：若1000V土壤一个游戏日自然蒸发200V（仅示意，忽略根系同期吸收与内部积分），**160V回到生态、40V逸散**；实际逐步结算应使用每步真实蒸发V。
- 光晕、粒子为永久流失元素的**可视表现**；未逸散的部分留在水晶球内，并改变生态比例、天气、土地和光晕色彩。具体视觉映射由美术/剧情系统后续定义。

## 3. 七日照顾Buff与条件随机

- 每日正常目标仍是6–10枚、单球20–100V、日总量300–500V（目标均值400V）。这些是**每天生成的球量目标**，并非必定从生态池取走固定400V的机制。
- **D1–D7全球照顾Buff**：七元素各至少一枚、且每种至少有一枚球≥50V，每日7–10枚、总量350–500V。**从D8开始完全取消七元素保底**；此后按当时Eco七维存量与其他条件决定元素球种类及数量。
- 若单纯按Eco比例抽样，有可能与教程七元素保底、初始元素偏科或生态储量不足发生冲突；需要为「Buff保底从哪里提取对应V」明确资源保障，不能凭空创建V，也不能把缺元素自动补进植物Growth。
- 生态存量、玩家选择及后续外部补给会逐渐改变球的生成分布。初期保留真实随机；不预设强行平衡七元素的自动纠偏比例。

## 4. 生态与高级玩法

- **生态表现**：七维比例将影响水晶球内天气、土地、光晕、粒子等颜色和气氛；具体图形和色值待美术处理。
- **后续外部补给来源**：来访客人的元素力形态、接待满意度、玩家探索方向、劳动成果、玩家购买的道具，可向指定元素Eco增加V。来源、数值、兑换成本及触发条件尚未确定，属于高级玩法。
- **元素过度充盈也有代价**：可能出现失衡或其他生态影响；当前只记设计方向，不设置任意过量阈值、惩罚或天气系数。
- 初始水瓜与种子比例相关，以及「仙人此前种植不理想，后留给主角」的叙事背景，归档于[11开局剧情记录](11-opening-tasks-and-processing.md)，不在生态数值阶段开发。

## 5. 后续需要确定的接口

1. Eco总量10000V的**容量口径**：是仅Eco、还是水晶球内所有可储存V与已转成G的整体容量；本轮只记录暂定总量尺度。
2. 随机初始七元素比例的取样限制、D1–D7保底与Eco现有量的守恒兼容规则、每日球量和概率权重。
3. 多地格Soil与共享Eco转移、球过期回流、根系吸收与生态之间的实际七维账本，避免元素重复创建或删除。
4. 成熟Growth如何最终离开生态系统，以及顾客/劳动/探索/道具等未来输入的计量口径。
5. 天气/地面/色彩和「过度充盈」的显示及反馈门槛，交后续体验与美术线，不提前设值。
