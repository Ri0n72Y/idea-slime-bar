# MVP｜水晶球七元素生态与凝聚供给

> 状态：数值曲线 v0.3 校准候选。生态容量、七维抽样顺序、Buff实际天数、土壤回流及植物元素流向属于已确认规则；归一化S曲线、κ=14、单球Beta分布与指数逸散系数为**待用户审定的候选数值**。只做解析期望及明示假设的确定性压力检验，未运行随机种子批量模拟、未验证完整领域生产系统。原根吸收、Reserve、Growth与器官阈值保持不变。实施归[Work #73](https://github.com/Ri0n72Y/idea-slime-bar/issues/73)。

## 1. 生态容量与初始七维分布

- 水晶球容量 **10000V**，仅统计全部开放地格的 `Soil[7]`、环境 `Eco[7]` 和尚处于球内的 `Ball[7]`；不计植物（包括Reserve／Growth／果实）、道具和已收走的元素球。
- 开局：首格Soil合计 **1000V**，Eco合计 **3500V**；日初首次凝聚前球内合计 **4500V**，不是满容量10000V。
- **Eco每种元素最低400V，平均500V**。初始化时为七日场地Buff按每元素 `7×50=350V` 预留基础数值，再每维增加50V，最后把剩余700V按开局种子的七维随机权重 `w_i` 分配：`Eco_i=350+50+700w_i`，`Σw_i=1,w_i≥0`。这些V都存于真实Eco账户中；不新建重复的元素余额。开局普通水瓜与种子使用同一个原始随机结果，外观仍是普通水瓜。
- 根系将Soil的V转进植物；生态的大部分转移由自然蒸发、土壤溢出及未收集球回归Eco完成。用户劳动、顾客与探索也可能补充元素，具体额度属于后续经济玩法。

## 2. 凝聚数量：Eco总量的S曲线（候选）

- `E=ΣEco_i` 决定当日可凝聚球数的平均尺度。原先**固定6–10球、每日300–500V及Buff期7–10球/350–500V的硬区间全部取消**。生态越充盈，球越多；枯竭时可以少于6球，甚至没有球。
- **推荐S曲线 v0.3（归一化、候选）**：令 `σ(x)=1/(1+exp(-x))`、`a=σ(-3500/900)`，则 `N̄(E)=8×[σ((E-3500)/900)-a]/(0.5-a)`，`E≥0`。锚点为**Eco=0→期望0枚、Eco=3500V→期望8枚**，高充盈时渐近约16.33枚，不是每天球数的硬上限。例：E=1000→0.64、2000→2.31、2500→3.79、3500→8、5000→13.69、6000→15.36枚。宽度参数比较：E=2000V时W=700/900/1200分别为1.59/2.31/3.06枚；E=5000V时分别14.41/13.69/12.94枚。**推荐暂保留900V**，不出现接近零时的正生成期望。
- **七维浮点向量候选**：计算每种元素在球内的 `T_i=Soil_i+Eco_i+Ball_i` 和 `p_i=T_i/ΣT`；抽取 `w~Dirichlet(κp)`，令 `q_i=N̄(E)w_i`，再按 `n_i=floor(q_i)+Bernoulli(frac(q_i))` 独立概率取整。取**κ=14**作为首轮校准值；无Buff时每日允许缺少元素，不强制七维平均。

| κ（Eco=3500V、七维比例均匀） | 无Buff期望球数 | 期望缺失元素种数 | 有Buff期望球数 |
| ---: | ---: | ---: | ---: |
| 7 | 8.00 | 2.14 | 10.14 |
| **14（候选）** | **8.00** | **1.47** | **9.47** |
| 28 | 8.00 | 0.95 | 8.95 |
| 56 | 8.00 | 0.57 | 8.57 |

以上来自Dirichlet单维Beta边缘分布与概率取整的**解析期望**，无随机种子批量抽测。若初始比例不均，缺失种数与Buff增量将随 `p` 改变。
- 每种球从其 `Eco_i` 真正扣除实际生成V，加入 `Ball_i`，不从Soil或植物虚构V。**普通球量级候选**：`V=20+80×Beta(1.5,2.5)`，单球20–100V、平均50V、标准差约17.3V，10%/90%分位约28.1/74.8V。原来均匀抽20–100V的平均为60V，会把初始每日8球的期望从400V抬到480V，因此这里选择保持50V均值。球数与球V分布是独立变量；Eco不足时不能超扣。

## 3. 七日场地Buff

- 本Buff附着**水晶球场地**，每份持续7个游戏日，初始水晶球自带一份；未来任意游戏日也可再次获得。日初生成前读取、生成后仅扣一次剩余天数；同日生成后新获得的Buff从下一次日初生效，读档不能重复结算。
- **Buff不改随机概率或S曲线**：先生成正常七维整数向量 `n`，然后逐维 `n_i'=max(n_i,1)`。每种元素**第1枚球固定50V**，原本抽中≥1枚则把第一枚定义为固定50V、其余照常抽20–100V；原本0枚则新增1枚50V球。只有零维度增加球数，已抽中的元素种类和球数不重抽；无10枚封顶。初始七维均匀时，κ=14给出有Buff期望9.47球、约473.4V（独立随机量的统计期望）。
- 初始每元素Eco至少400V，其中**连续7个生效日保底共需350V**。为确保原本抽到的高量普通球不会提前耗尽后续保底，生成前对每个元素保留 `50×剩余Buff生效日` 的可用额度；生成当天50V保底后，其余普通球只能使用扣除**后续生效日需用的50V/日**后剩下的Eco。预留是Eco内的可用性检查，**不新建或二次扣除储量**。资源不足的普通随机球取消实际生成，不能重抽为免费元素。后续再获Buff的不足额与叠加方式仍归统一Buff系统处理。
- 场地Buff的七次实际生效结束后，下一次生成自动回到普通随机；不按D1–D7或D8日号做判断。

## 4. 蒸发、土壤溢出与指数逸散（候选）

- **土壤自然蒸发**保持原 `80%/d` 留存结算；植物自身的自然流失、未收集球在次晨消失时的真实剩余V，也按对应元素记录流失事件。根系正常吸收及果实性状复制不属于自然蒸发。
- **逸散比例由球内充盈度决定**。本轮使用环境＋土壤总量 `C=Σ(Eco_i+Soil_i)` 作为曲线输入，和容量检查所用的 `Σ(Eco+Soil+Ball)` 区分。蒸发的每维元素 `X_i` 按 `Eco回流_i=X_i×(1-r(C))`、`永久逸散_i=X_i×r(C)` 处理。
- 指数候选：`r(C)=0.2×exp[ln(4)×(C-4500)/5500]`（`0≤C≤10000`）。**初始C=4500V时逸散20%**；C=2000/8000/10000V时分别约10.7%/48.3%/80%。低充盈逸散减少，光晕减弱且球内逐渐黯淡；接近满容量时粒子逸散明显增强。20%初始基线来自原八二比例，指数斜率与满容量80%仍属待体验调参值。
- **土壤容量仍1000V**。一次浇灌后，Soil七维合计超出1000V时，先按原公式比例裁剪，再把各维被裁掉的全部V返还Eco，**不按指数逸散**。D1土壤已满时浇入球必然产生溢出；之后是否溢出取决于当天土壤剩余和实际投入。回流属于Soil→Eco的内部转移，不额外产生V。
- **球内总容量10000V是硬上限**。外部补给或植物蒸发回流等导致 `Σ(Eco+Soil+Ball)>10000V` 时，超额新增部分直接变为光效/粒子逸散，余量留在Eco。此前土壤溢出只是球内内部转账，不增加球内总量。超额逸散与上述自然蒸发比例不重复收费。
### 4.1 植物元素流向（已确认）

**保留原Growth、七维亲和、分流与器官阈值**。以实际取得、释放或搬出的V记录生态收支；G仍负责生长阶段、亲和与材料性状，不以G数值反推实际V，不把回流记录当作可再次消费的植物养分。

| 事件 | 实际元素V去向 |
| --- | --- |
| 根系吸收 | Soil→植物，Seed/Seedling累积的1V→1G在进入Sapling时转入Reserve一次；不算永久逸散 |
| Sapling主干100G周期塑形 | 固化亲和后，释放本周期实际投入主干的全部V（含该结算步实际投入导致的阈值超额），清除本周期对应记录；按当时Eco+Soil充盈度分为回归Eco及永久逸散 |
| Bud→SmallLeaf | 芽已取得的V随新叶留存；芽的Growth重置不造成额外逸散 |
| SmallLeaf→LargeLeaf | 已取得的V继续留在叶内；叶Growth清零不释放元素 |
| LargeLeaf自身生长 | 原自身实际取得V的60%留在叶内，40%属于自然释放；对释放的40%应用生态回流/逸散比例一次。Growth计算保持原亲和与效率 |
| 花苞、花、青果、成熟果 | 实际取得的V持续随该生殖器官留存；12/40/90G阶段变化、亲和固化、元素反应与富集不另改写真实V记录；未取用的父级预算不算释放 |
| 采摘材料 | 真实材料与对应V记录从植物转到洞天地面；只有实际移出洞天时才计外流，采摘本身不再另扣一次 |
| 洞天内清理或自然分解 | 被移除部分的剩余真实V（包括尚存Reserve、未完成周期与器官留存）释放，按生态分流处理；已移走、已释放的V不得重复回流 |

- 主干塑形举例：实际投入100V、当前逸散率20%时，80V返回Eco、20V逸散；不因此修改已固化的亲和。Seed/Seedling转Reserve与Sapling主干塑形属于不同事件，不重复释放初始Reserve。
- 植物收支可按七维维护实际V的去向记录（主干本周期、芽、叶、果，以及既有Reserve）。这是来源核算，不是第二套可用Growth或Reserve。原有掐芽回主干的操作若启用，实际V随原Growth转移，不另释放。
- 容量10000V仍只计Soil+Eco+Ball；植物与地面材料留存V不计入容量。环境可用量下降不等于整个洞天永久失去元素。若统计洞天整体收支，应另外包含植物和实际尚在洞天内的材料/道具，并区分外部输入、真实逸散、材料移出；加工性状不作V来源。
- 自然释放统一复用§4的指数分流和容量裁剪，不额外增加独立每日发光消耗或器官每日蒸发率。具体分解触发时点、材料重新带入的处理（尤其加工后的产物）、复花阈值仍待各玩法合同明确。已确认同一片叶可长期培育并反复开花结果，采果不清空母叶留存V或性状，也不要求清理整株；大树阶段会扩展叶位/开花结果位，数值待定，详见[09](09-daily-growth-balance.md#长期培育与复花已确认方向)。

## 5. 环境表现与后续来源

- Eco与Soil的七维比例和总充盈度影响天色、土地、天气、光晕和粒子。**总量低时黯淡**，接近10000V时逸散增强。具体色值、天气与低/高亮度映射留给美术设计。
- **自然视觉表现**：以`C=Σ(Eco+Soil)`判断，**C<2000V时水晶球黯淡、几乎不发光**。具体表现曲线待美术；该阈值仅描述自然状态，不触发教学、剧情、奖励或强制停止Growth，也不作为初期体验的时间目标。
- **当前正常经营标定先假定玩家行为不额外补充元素**，仅计算自然逸散、土壤/植物转移、回流及材料移出。来客携带元素、服务满意度、玩家劳动/探索或购买道具等持续补给仍为**可讨论的未来机制**，暂未确认来源、公式、数量，也不作为本轮日常收入。
- 生态总量高可能产生额外负面效果，但不在本轮增加惩罚、经济数值或强制阈值。
- 包含植物在内的更广义元素转移大部分属于内部循环；水晶球10000V容量仍只统计Eco＋Soil＋Ball。树木Growth阶段、亲和、果实加工性状继承由[09](09-daily-growth-balance.md)与[11](11-opening-tasks-and-processing.md)持有，不在生态生成器中重新定义。

## 6. 曲线标定与条件压力检验

### S曲线、随机分配与单球V

- 首轮推荐候选：**零点归一化S曲线，Eco中点3500V、宽度900V、初始期望8球**；Dirichlet **κ=14**；普通球使用**20+80×Beta(1.5,2.5)**，均值50V。所有数值走独立配置，不修改已确认Growth/器官曲线。
- Eco=2000/2500/3000/3500/4000/5000V、七维比例均匀时，正常期望球数依次约2.31/3.79/5.74/8.00/10.26/13.69；κ=14下Buff补缺后期望约7.01/7.18/7.98/9.47/11.28/14.34。**Buff只改变零维度的数量下限，不把低Eco的自然球量强行改成8枚以上**。缺乏实际Eco扣款能力时先应用储量守卫。
- 自然蒸发指数逸散曲线先保留 `r(C)=0.2×exp[ln(4)×(C-4500)/5500]`：C=2000/4500/8000/9000/10000V时逸散约10.7%/20%/48.3%/62.2%/80%。如将10000V端点改为60%或90%（仍保留4500V的20%），C=8000V分别约40.2%或52.1%。暂选**80%@10000V**作为可调方案，不将此视为已证明的长期稳态。

### 正常种植收支校准范围

当前只考虑情景A：单株、正常收球与浇灌、正常收获，不计来客、劳动等日常外部补给。由真实24uh成长和§4.1回流逐日计算，观察首果成熟、Buff到期、日常浇灌供给与元素收支。此前忽略植物回流的七日压力检验不能作为新规则的产量预测或每日补充目标。

单日参考核算（非完整游戏验证）：取土壤1000V、Eco3500V、Reserve140V、一片大叶和40G青果的参考状态，七维均匀初值、24uh原成长公式与新版日速率、不触发新器官事件。土壤蒸发约183.7V，根吸收151.8V，主干投入96.6V，大叶投入8.3V（其中3.3V释放），果实投入33.1V，Reserve净增加13.8V。逐uh用候选指数逸散率分流后，回Eco约150.5V、永久逸散36.5V，日末Eco+Soil约4315.1V。本日未触发主干100G周期；后续应按实际周期释放，不能把主干每日投入固定为永久流失。此算例仅用于验证记账关系，不代表随机开局或真实产率。
