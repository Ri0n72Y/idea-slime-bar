# MVP｜水晶球七元素生态与凝聚供给

> 状态：2026-11-21规则补充。确认水晶球**总元素V上限10000**、首次状态4500V、按元素总量加权凝聚、首周强制保底、蒸发80/20分流；原土壤吸收、Reserve、Growth、器官阈值不变。数值实施归[Work #73](https://github.com/Ri0n72Y/idea-slime-bar/issues/73)，剧情与美术另行设计。

## 1. 水晶球总元素量

- 水晶球的七维总量账户包括 **Soil[7]＋生态环境Eco[7]＋当前已凝聚而未被收集的元素球Ball[7]**，**合计容量上限10000V**；这是真正的上限，不是开局数量。
- **道具、玩家已收入库存的物品、植物（含Reserve、器官Growth与果实）不计入上述10000V**。植物自身仍按既有V/G与亲和规则成长；它的元素自然蒸发时进入下述生态回流环节。
- 初始值：首块土地Soil合计**1000V**，生态环境Eco合计**3500V**，初始元素球若尚未生成则为0；水晶球总量为**4500V**，距离上限尚有5500V容量。七维初始比例与开局种子的随机元素分布关联，同一初始普通水瓜也沿用该比例，但外观没有元素特征。
- 元素球从生态环境中凝聚：生成元素 `i`、生成量 `v` 时，**Eco[i]减少v、Ball[i]增加v**；收集后Ball扣除对应v并转到玩家持有账户，浇水时再转到相应Soil。元素球转移不会凭空增加球内V。

## 2. 自然蒸发、回流及逸散

- Soil保持原**每日80%留存**，每步真实扣除的自然蒸发元素记为 `SoilEvap[i]`。植物中的元素也存在自然蒸发／流失：以实际植物流失的相应七维元素量 `PlantEvap[i]` 记账，**不能把未流失的储量或已形成的Growth整体当作蒸发**。
- **土壤蒸发和植物蒸发都向Eco回流元素**。对它们每一维实际蒸发量，**80%回到Eco[i]、20%从水晶球以光晕／粒子逸散并退出生态系统**；植物流失的V/G量如何在原Growth模型中记账和折算，留到实施合同确定，不改变原成长公式。
- 当日**未收集的元素球到次晨消失**：其未收集的真实剩余元素量同样80%回Eco、20%永久逸散，完成结算后删除Ball实体；同一份V不得重复回流或再次领取。
- 示例：若土壤真实蒸发200V，则160V回Eco，40V逸散。**80/20作用于已蒸发的V，而非Soil整体**；植物及元素球的流失同理。
- 自然流失回流与外部补给均受水晶球10000V上限限制；边界处理及植物G流失的V计量需在工程配置合同中规定，暂不新增处罚或数值倍率。

## 3. 元素球生成及前七日Buff

- 常态每天**6–10球**，单球**20–100V**，日总量**300–500V、平均目标约400V**；实际生成量从Eco扣除。
- **正常元素类型随机依照球内每种元素的总量加权**，即 `Total[i]=Soil[i]+Eco[i]+Ball[i]`。Total越高，该元素被选中的概率越高；保留随机波动，允许重复与缺某种元素。概率函数需满足随Total单调增加，具体权重曲线与生成顺序留待调参。
- **D1–D7全球照顾Buff**：每个游戏日强制对**七个元素各生成至少一枚、每枚保底50V**，这七次生成分别从对应Eco[i]扣除真实V；剩余0–3枚依照常态权重随机，教程日总数7–10球、总量350–500V。初始环境资源**已保证足以支付首周保底**，无需新增「缺元素免费补给」机制。
- **D8起Buff彻底失效**：取消七元素必出与50V保底要求，全部按环境总量及其他已开放条件随机。
- 强制保底与正常随机都不能无成本生成球；只有被指定的生态来源才允许向Eco补入V。具体多余球的V分配、总量约束下的抽取算法仍需定稿。

## 4. 生态变化与高级玩法方向

- 生态七维比例会反向改变下一轮元素球生成权重，也影响球内天气、地面、光晕及环境粒子的色彩。具体视觉映射留给美术。
- 后续外部补充来源：来客元素力形态、服务满意度、探索方向、劳动活动、购买道具等，均可能向Eco增加对应元素。属于**高级玩法**，暂不决定奖励量或触发条件。
- **过度充盈也可能产生负面生态影响**；10000V是已确认总容量上限，失衡效果与高充盈负反馈机制仍待设计，当前不自行设定阈值。
- 初始种子与普通水瓜的同源元素比例，以及仙人此前试种未成功的背景只作为剧情素材，见[11](11-opening-tasks-and-processing.md)。

## 5. 尚需细化的参数／接口

1. 具体的单调随机权重公式，以及保底之外额外球的大小和当日总量约束如何同时满足。
2. 植物蒸发在既有V/G与器官账本中的真实损失量、转为Eco回流单位的计算，避免重复记录同一次蒸发。
3. 生态总量接近10000V时，对新投入和80%回流部分的容量边界处理。
4. 后续生态天气、失衡风险、顾客／劳动／探索／购买道具的供给公式。

**不再作为待决事项**：10000V统计范围、首周保底的元素来源、D8退出保底、80/20蒸发分流。水果加工产物的元素值仅用于性状，不要求跨产品守恒，见[11](11-opening-tasks-and-processing.md)。
