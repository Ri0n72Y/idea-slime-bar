# MVP｜1d 成长体验曲线与数值基线

> **版本：教程体验曲线已由用户确认，2026-11-19。** D1–D7的主要阶段、教程期七元素保底、经营教学方向属于策划目标；本页参数表仍是待细拆的**候选数值**，不代表当前代码已实现或算出了稳定的每日产量。下一轮再按每天的根吸收、Reserve、Growth与器官预算校准。参见[工坊主布局](10-workshop-first-layout.md)。

## 1. 每日玩法与教程终点

- 游戏以**制作经营、资源收集**为主：白天在工坊接待顾客、购买或订购 NPC 原料、制作饮品/餐点/药剂、交付订单，同时收集元素球；通过水晶球进入独立种植区。
- **D1首次激活种植时**：NPC额外赠送一次性补土道具。玩家在新手引导中使用后，初始种植地格的七维 Soil 总量直接补满至 **1000V**。这是教程开局供给，不占当日随机元素球的约400V额度；七维构成与道具具体名称留待下轮细化。
- **关店后每天集中浇灌一次**：将已持有的任意数量、任意元素球分配到一格或多个地格，一次确认当天配置；结束今日后成长推进 **1d**，次晨展示真实阶段变化。
- **D1播种；D2–D7每天早晨看见一个主要成长节点；D7首枚自产水瓜成熟**。玩家采摘、加工并交付自己的第一件水瓜产品后，完成教程。阶段由真实Growth事件驱动，体验目标不授权按天硬编码造果。
- 教程前6天，经营使用从NPC购买或提前订购的果子、食物、药材，不依赖玩家自产果。玩家在这段时间分别熟悉饮品、餐点、药剂、采购、订货和多类顾客。具体菜谱、制作设备、价格与订货周期另案设计。
- 白天操作、场景切换与真实经过时间不推进游戏成长；点击结束今日才产生一次1d的结算。

## 2. 随机元素球与7天照顾Buff

| 项目 | 正常游戏日 | 教程期 D1–D7 |
| --- | --- | --- |
| 每日数量 | 6–10枚 | **7–10枚**：7种元素各至少1枚，保底条件优先于常态6枚下限 |
| 单球V | 20–100V | 20–100V，**每种元素至少一枚球≥50V** |
| 每日实际总量目标 | 300–500V | **350–500V**：七维保底共至少350V |
| 每日总量期望 | 约400V | 约400V |
| 元素生成 | 七种元素随机，可重复、可缺某一种 | 先满足七元素保底，额外球再按随机规则产生 |
| 随机调节 | 玩家Buff与顾客倾向可以改变供给分布 | 新手照顾Buff持续7天，教程结束后不再自带七元素保底 |

- 保留真正的随机内容：正式阶段可能缺元素；玩家自行选择Buff、调整顾客倾向，影响之后生成的元素组合。**不修改七元素独立Growth预算来弥补缺元素**。
- 单球20–100V及每日300–500V是两层约束。独立随机抽球的原始总和不一定落在指定区间，生成器需在保留元素随机性的同时满足每日总量区间；具体概率权重、浮动分配算法留待细化。教程期七元素保底同理；不能将最低350V误写成300V。
- D1 NPC补土道具是独立的一次性开局资源，七维Soil总量补至1000V；后续仍按根吸收、蒸发、容量与玩家主动浇灌规则结算。
- 原单球固定50V/每日固定8球与“玩家主动逐枚凝聚”的玩法口径不再用于新设计。收集后的实际V保存于玩家持有库存，按种植规则转移而不复制；持有上限与跨日损耗仍待定。
- 1d策划不再安排随机种子批量模拟，后续先核对具体状态和数值约束是否满足体验曲线。

## 3. 1d 整数化候选基线

**1d = 旧24uh对应的一次完整成长结算**。游戏日参数从体验目标推导，保留旧领域机制；原值仅作迁移参照。

| 参数 | 原24uh等量 | 新1d候选 |
| --- | ---: | ---: |
| Soil 每日保留率 | 0.99^24 ≈ 78.6% | **80%/d** |
| Seed 根系总吸收速率上限 | 48V/d | **70V/d** |
| Seedling 根系总吸收速率上限 | 44.4V/d | **70V/d** |
| Sapling 根系总吸收速率上限 | 384V/d | **400V/d** |
| Sapling Growth 参考预算 B0 | 129.6V/d | **130V/d** |
| 土壤容量（七维合计） | 1000V | **1000V** |
| Reserve 容量（七维合计） | 180V | **180V** |

- 上表的吸收上限、Growth预算都属于**速率上限或参考预算**，不等于当日必定取得的 V/G。实际Root吸收还受土壤总量、RootPreference、七维通道与充盈限流；Reserve→Growth仍使用当前S形函数与逐元素亲和、各器官分流及库存截断。
- 继续保留 Tree/叶/生殖的七维独立账户，1V→G转换、亲和继承、叶片竞争、元素反应、成熟后自然富集与物质守恒。**不得把所有元素合并成通用成长能量**。
- 先将所有展示/设计公式以 d 表示；引擎是否继续以 Δd=1/24内部积分，交由实现阶段按非线性阈值和04:00出芽事件语义核对。每日合法随机出芽机会只发生一次，不能由积分子步重复触发。

### 成长阈值（本轮候选，待验证可行性）

| 原阶段事件 | 旧阈值 | 新候选 |
| --- | ---: | ---: |
| Seed → Seedling | Tree累计45G | **50G** |
| Seedling → Sapling | 同一Tree累计90G | **100G** |
| Active Bud → SmallLeaf | Bud20G | **20G** |
| SmallLeaf → LargeLeaf + FlowerBud | 本叶26G | **30G** |
| FlowerBud → Flower | 生殖累计12G | **15G** |
| Flower → GreenFruit | 生殖累计40G | **40G** |
| GreenFruit → MatureFruit | 生殖累计90G | **90G** |

Seed/Seedling的Tree Growth为同一累计账户；Sapling开始先转为Reserve并建立首芽；花苞至成熟果共享连续的生殖 Growth 账户，不分别清零或把15G+40G+90G相加。

## 4. 已确认的D1–D7教程体验曲线

**日号指玩家早晨看到的阶段；D1营业后首次关店结算产生D2的结果。**

| 游戏日 | 早晨可见的植物主变化 | 白天经营/教学重点 | 原料来源 |
| --- | --- | --- | --- |
| **D1** | 播种，使用NPC赠送道具将首块土地补满至1000V | 认识柜台、接第一位顾客、购买果子、制作第一杯饮品并交付 | NPC即时购买＋一次性补土道具 |
| **D2** | **Seedling：破土发芽** | 第一次餐点顾客，认识食材与餐点加工 | NPC果子与食材 |
| **D3** | **Sapling：长成幼树，并出现首芽** | 药剂顾客，认识药材、配方与材料差异 | NPC果子、食材与药材 |
| **D4** | **SmallLeaf：第一片叶出现** | 学习订货、规划材料和次日到货 | NPC订购 |
| **D5** | **LargeLeaf + FlowerBud：大叶与花苞** | 多类顾客和订单同时出现，安排工坊加工与材料 | NPC采购与订货 |
| **D6** | **Flower / GreenFruit：开花并结青果** | 独立完成一次采购→加工→交付流程，为自产原料做准备 | NPC原料 |
| **D7** | **MatureFruit：首枚可采摘水瓜** | 采摘→加工自产水瓜→交单，结束教程 | 自产水瓜＋NPC补充 |

- 每天至少有一个**清晰可见的目标变化**；允许出现自然发生的其他器官变化，但不要求每个玩家的额外枝叶、七维偏向和品质一致。
- 第七天首果是教程目标，受真实吸收、Reserve与器官Growth驱动，不能按日号直接设置MatureFruit。教程保底Buff解决七元素缺失，**不自动补足不足的Growth或绕过生长门槛**。
- 教程推荐先用一个种植地格示范；额外地格的开放及分流资源教学可在首果后展开，避免改变前七天学习节奏。

### 夜间结算与主阶段对齐

| 当日关店结算 | 期望次晨可见结果 | 主要Growth账户 |
| --- | --- | --- |
| D1→D2 | Seedling | Tree 累计达到50G |
| D2→D3 | Sapling＋首芽 | Tree 累计达到100G |
| D3→D4 | SmallLeaf | Bud 达20G |
| D4→D5 | LargeLeaf＋FlowerBud | Leaf 达30G |

## 5. 经营供给与经济学习

- **NPC即时购买**：当天取得果子/食材/药材，初始经营缺货时能继续做饮品、餐点和药剂；定价、货币与原料清单待细化。
- **NPC提前订货**：作为低成本/计划性供给渠道，玩家在D4开始学习预计需求与安排到货；价格优势和到货日暂不写死。
- **自产果实**：在D7第一次进入生产链，作为教程闭环。与外购材料的成本优势、亲和/风味价值以后设计。
- 顾客需求从饮品、餐点、药剂逐日拓展，后期允许混合并发。现有MVP仅有水瓜→剥壳→榨汁→装杯的完整功能链，**餐点/药剂/NPC采购属于新规划，还需Lead划分后续实现范围**。
- D7教程完成条件优先采用「实际采摘、加工并交付首个自产产品」，而不只检查植物成熟提示。既有委托截止日、奖励与地格成本本轮不定稿。

## 6. 下轮数值细拆：必须解决的约束

**已确认的前期阶段阈值：**Seed的Tree Growth累计50G成为Seedling，Seedling继续累积50G、达到总计100G进入Sapling；两个阶段根系吸收上限均采用**70V/d**。按照D1 NPC道具补满1000V、教程七元素保底、NPC引导每日完整浇灌，以及七维等量补土/浇灌的标定条件，以80%/d保留率和原根系对数公式按1/24d内部子步估算：**D1约65G，D2经过约13/24d达到100G并进入Sapling**。这些是设计计算参考，后续开发以领域实现对账；不需要随机种子批量测试。

此外逐日拆解：
1. D1–D3：以D1 NPC道具将首块土地补满1000V、教程七元素保底、NPC引导完整浇灌为既定前提，确认70/70V/d上限与累计50/100G阈值的领域实现和状态转换；沿原根系对数公式与七通道吸收计算，不另加补偿机制。
2. D3–D5：180V Reserve、B0=130V/d、当前S型充盈和Bud/Leaf预算分流，核算首芽、20G小叶和30G大叶的日终节奏。
3. D5–D7：生殖预算先后达到15/40/90G，以及多个叶位同时生长时的真实竞争关系；调到第七天可达首果目标。
4. 才讨论每日300–500V供给和Buff、玩家对顾客类型与后续随机结果的调节、外购与自产收益差异、委托和经济数值。

本轮**仅记录体验曲线与参数候选**，无随机种子测试、无参数实现、无经营系统开发。旧的512种子分布、随机早熟率与固定8球结论不再是新设计的验收标准。经Lead审定后由Coder另行更新旧文档及实现。
