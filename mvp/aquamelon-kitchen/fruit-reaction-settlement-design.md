> **范围界限（2026-10-10确认）**：本稿不讨论味道辨析、风味强度、形态表现、口味倍率或料理结果。既往风味设想只算历史背景，不用于推导反应物质量，也不进入本稿的待解决事项。

> **已解决的语义冲突（用户于2026-10-09明确）**：花与果实从开花开始到结果、成熟，始终属于**同一个 Growth／物质量账户**；初次成熟前，该账户为一份七维 Growth 向量，总量到 **90G**；反应之后，原有元素转为稳定反应产物并继续占用同一账户，没有独立的 `FruitElementAmount[7]`，也没有花期30G被剔除后重新积累的果实元素池。旧版 [growth-system.md](growth-system.md)、[growth-balance-baseline.md](growth-balance-baseline.md)、[growth-foundation-requirements.md](growth-foundation-requirements.md) 仍存在 Flower 0→30、Fruit 30→100 和第二个 `FruitElementAmount[7]` 的不同口径；**这些旧合同待统一修订**，不应把它们视为真实存在的双池。

## 1. 已确认：唯一资源与主动反应门槛

- 花与果实的生命周期共用**同一个七维 Growth／物质账户**：Flower 从0G开始增长，Green Fruit 完整继承花期积累，到90G成为 Mature Fruit。**成熟前是七维原始元素 `E_free[7]`，反应后同一账户拆分为未反应的 `E_free[7]` 与已转换的稳定 `Products[]`**。后者不是临时附着，也不是第二套生长积累；不存在独立的 `FruitElementAmount[7]`。
- 形态边界按**阶段切换事件**记录：Flower 0→30G、Green Fruit 30→90G；到达90G触发一次初次成熟和元素反应。反应后原始元素转成等质量的稳定反应产物，**总物质量不因反应改变**；成熟阶段不回退或重复触发成熟。
- 本轮初次成熟数值讨论以七维积累总量 **90 G** 为基线，单位 **1U = 30 G**。
- **主动发动一次反应必须有该元素严格超过 1U（>30 G）**；恰好 30 G 不具有主动资格。
- 初次成熟总量为 90 G 时，最多 **两个**元素能同时拥有主动资格；七元素均匀分布时没有可发动的双元素反应，应当是普通水瓜。
- 只有一个元素拥有主动资格且没有可执行的双元素反应时，可形成单元素性状果（具体表现另定）；不因微量其他元素自动触发反应。
- **被动参与**的已有元素不要求 >30 G：只要对应元素尚有正的可反应存量，就可以被新触发元素消耗；0 G 不反应。这与主动资格是两个条件。
- 元素反应本身是**离散事件**。成熟与其后的明确富集触发结算；同一批存量不能因为下一 Tick 仍满足阈值而无条件反复触发。首次成熟时总占用刚好90G，反应结算后仍是90G；此后新增 Growth 加入同一账户的自由七元素，而成熟阶段锁存不回退。

示例：

| 七维中显著部分（初次合计90G） | 有主动资格的元素 | 初次成熟 |
| --- | --- | --- |
| 七元素均分（各约12.86G） | 无 | 普通水瓜 |
| 水90G | 水 | 水性状果；无第二元素反应 |
| 水60G／火20G／雷10G | 水 | 水性状果；火还不能主动触发 |
| 水50G／火40G | 水、火 | 立即按默认结算顺序发生蒸发 |
| 水30G／雷30G／冰30G | 无 | 不发动反应 |

## 2. 已确认：一次反应只投入 1U 的触发元素

一次成功发动的反应，触发方使用 **1U = 30 G**，而不是一次投入它的全部元素存量：

```text
trigger_after = trigger_before - 30G
target_consumed = min(target_before, 30G × reaction_coefficient)
target_after = target_before - target_consumed
```

- 触发前要满足触发方 >30G；被反应方只需存在有效正存量。
- **不采用**战斗附着的 20% aura tax；这些数值代表果实的真实七维可消耗资源。
- 被消耗的**自由元素**不再作为自由残留参与另一条普通反应，但按实际消耗之和形成稳定产物，仍占用相同质量预算；扣减下限为0。
- 被反应方不足标准消耗时仍可触发一个完整离散反应，不按消耗比例产生“半次反应”；**稳定产物只记录实际消耗量**，不能凭空补足缺失的原料。任何反应产物只按实际消耗的原料量记账。

已确定要依照原神消耗方向的蒸发／融化例子：

| 触发元素 → 被反应元素 | 原神基础增幅 | 被反应元素系数 | 每次最多消耗的被反应元素 |
| --- | ---: | ---: | ---: |
| 火 → 水（逆蒸发） | 火×1.5 | 0.5 | 水15G |
| 水 → 火（正蒸发） | 水×2 | 2 | 火60G |
| 火 → 冰（正融化） | 火×2 | 2 | 冰60G |
| 冰 → 火（逆融化） | 冰×1.5 | 0.5 | 火15G |

算例：

- 水50G＋火40G，以火触发一次蒸发：**自由水35G、自由火10G，蒸发产物45G，总量90G**；火的40G只投入30G。
- 火50G＋冰40G，以火触发一次融化：**自由火20G、自由冰0G，融化产物70G，总量90G**；冰原本只有40G，按上限清零。
- 水60G／火20G／雷10G 初次成熟不反应；后续火由20G增加到31G，首次取得主动资格后，以火1U触发：**自由水45G／火1G／雷10G，蒸发产物45G，总量101G**（此次新增11G，消耗火30G和水15G）。

以上是**单次反应数值**。触发方一次投入完整30G后，**若剩余触发元素不足1U（30G），本次连续反应立即结束**，不支持不足1U的零头发动第二次反应。是否能在剩余足量时继续，还必须遵守SRP、有效事件与防重复条件。

## 3. 已确认：初次成熟有两个活跃元素时直接反应

取消早先提出的“50水／40火先成为不稳定果、等待占比提高10个百分点”方案。两种元素均 >30G 时，**初次成熟立刻结算**。

缺乏先后事件的初次成熟采用 KQM 社区研究的实验性元素优先级作为**水瓜默认触发方向约定**：

```text
雷 > 火 > 风 > 冰 > 冻结 > 水 > 草 > 岩
```

- 该表是 KQM 对特殊多附着反应的**实验性排序**，研究者报告过例外；**不等同于原神对任意无序元素池的官方触发方向**。
- “冻结”是特殊反应状态，并非七维元素向量的第八种元素。单纯从 E[7] 选择触发方时跳过该项。
- 此排序用于为**初次成熟时两个无序活跃元素**选择默认触发方向；发生多反应竞争时，还要另行采用 SRP（Simultaneous Reaction Priority）的**反应先后表**。不要把元素排序、SRP、风染色／元素吸收优先级混为一谈。
- 火／水：默认**火触发蒸发**；火／冰：默认**火触发融化**。这让火蒸发、火融化可在初次成熟获得。
- 水触发蒸发、冰触发融化，主要通过成熟后挂果的**新富集触发事件**获得。培养难度由需要的额外阶段自然形成，而不是人为指定稀有度。
- 不存在有效反应关系时不能强行产出反应果；草＋冰等特殊共存边界待下一轮逐项列出。

## 4. 已确认：挂果富集提供真实“后发生”顺序

- 初次成熟不摘果，元素仍能继续积累，但从**总占用90G**开始，其增长速率随全体物质量**指数下降**，到后期几乎不能再增加；稳定反应产物也占用这一容量。此阶段不重新执行物理成熟。
- 原本不具主动资格的元素，在后续富集中**首次从 ≤30G 跨越到 >30G**，可成为明确的新触发元素。
- 例如水60／火20／雷10，之后补火跨越30G，按“火后施加到水”结算蒸发；同理，可先保留火性状，后续补水或冰取得较难获得的反向蒸发／融化。
- 已生成的反应产物不会因为自由元素耗尽而消失；后续只有明确允许反应的特殊中间产物能够继续转化。
- 此处的时间顺序只是**元素存量发生增长的事实**，不是新增一个临时附着元素池。

**未定**：一个元素在上次反应后已处于 >30G 状态，再持续增长多少才构成新的一次主动事件；以及同一次结算中是否允许多个1U份额、它们如何被分配。现在不能让每个 Tick 因库存仍 >30G 而重复触发。

## 5. 已确认：多元素按 SRP 尝试，实际结算仍需消耗规则

初次成熟最多两个主动元素，但后续挂果可让**第三个元素**加入。不同反应对资源的处理不同，不能全部按蒸发倍率公式解释：

- **即时消耗**：蒸发、融化、超载、超导、扩散、结晶等；系数需按各反应核定。
- **持续／共存**：感电允许水雷并存，但**不是零消耗**；原神感电每次周期结算会消耗双方附着量。我们需要把持续反应映射到果实的有限成熟／挂果事件，不引入实时附着池。
- **转换成特殊状态或产物**：冻结、燃烧、原激化、绽放等不能一律视作两个元素瞬间扣光。
- **非消耗特殊状态**：超激化／蔓激化不会在触发时减少已有激元素状态；这是对特殊状态而言，不代表初次建立状态无成本。
- 风扩散一般涉及火／水／雷／冰的元素传播；原神扩散传播出的元素量可能高于原附着实际消耗量。水瓜内部是否允许扩散改变分配、以及如何避免无条件增殖，仍须单独设计。
- 星月／月反应**暂不参与**当前成熟结算，等待未来环境系统提供特殊条件。

**已确认的 SRP 示例：** 水雷先形成感电形态，后续冰获得主动资格时，按SRP**优先尝试超导（冰＋雷）**。如果冰从31G发动一次反应，消耗30G后仅余1G，**本次结算停止，不再冻结**。仅当后续出现新的有效富集事件或当次仍有足够完整反应份额、且满足合法连锁条件时，才可能继续尝试冻结。SRP提供优先级，**不能跳过每次1U的份额要求**。

## 6. 已确认：反应原料消耗与产物质量守恒

```text
Flower/Fruit 同一成长／物质账户（初次成熟时90G）
  → E_free[7]：七维自由元素
  → 按触发资格、默认方向或SRP选反应
  → 触发元素实际投入30G，被反应方按消耗系数扣减
  → Products[] 增加双方实际扣减总量
  → M = ΣE_free[7] + ΣProducts[i].amount
  → 反应不改变M；只有后续生长输入改变M
```

- **守恒关系**：`ΔProducts = Δtrigger_consumed + Δtarget_consumed`，因此 `M_after = M_before`；产物占用同一份容量。被反应方不足标准份额时，只记录其实际被扣数量。
- **超导算例**：30G冰＋30G雷实际转化，生成60G超导产物；原材料对应份额退出自由元素，产物不能拆解回冰或雷。
- **稳定终产物**不再充当其它普通元素反应的原料；仅草原核和激元素存在已明确的受限进阶资格，具体数量结算见下文。
- **范围外历史记录**：此前讨论过60G超导产物的风味倍率，但该倍率绝不增加其60G质量；不在本稿继续分析。

### 6.1 成熟后指数富集衰减

**已确认的设计意图**：90G是成熟后富集效率开始明显下降的边界；继续挂果可以引入第二／第三元素，但总量越大，元素补入越困难，至后期几乎停止。**自由元素＋稳定产物共同占用容量**，因此无法靠反复反应清空元素、解锁无限富集。

暂可用下列**候选形式**讨论（未锁定系数）：

```text
M = ΣE_free + ΣProducts
R_enrich(M) = R_at90 × exp[-k × max(0, M - 90)]
k > 0
```

这里的指数衰减只影响**90G以后**的成熟果富集效率，不改变花期／青果阶段的母叶养分流。**指数减速本身在无限时间下并无数学上的有限硬上限**；若需要严格容量上限，应另外配置 `M_cap > 90`，具体 `k`、`M_cap` 和实际培养时间曲线都暂不定。指数减速与硬上限如何组合，待数值模拟后锁定。

**最低可达性检查**：初次成熟的纯水90G果若要后续新增火>30G并触发蒸发，反应前必须能够积累到**总占用 >120G**，因为产物占额不释放空间。因此，若希望这条培养路径可行，硬上限必须 **M_cap > 120G**，并且指数衰减不能让90→120G所需时间失去游玩意义。反之，初次成熟已带有20G火的水60／火20／雷10，只需后续加火超过10G即可跨门槛，所需总量接近100G。该差异正是培养策略，不代表固定所有第三元素都要再增长30G。


### 6.2 普通终产物与两类可进阶中间产物

- 普通反应产物是独立的稳定终产物，例如超导不能被拆回雷与冰，也不能借原材料身份再次参加普通元素反应。
- 草原核（`DendroCore`）与激元素（`Quicken`）是仅有的两类已确认可继续参与**指定反应**的中间产物；它们仍占用同一成长/物质总容量，不能退回自由水、草、雷。
- 后续雷、火或草元素必须具有合法新增触发事件，并投入完整1U=30G；当前已存在的中间产物是被动对象，不要求它自身>30G。
- **已确认**草原核遇雷/火后**全量消耗**，转化为对应超绽放/烈绽放终产物；**已确认**激元素遇雷/草发动超激化/蔓激化时**消耗0G**，新投入的30G元素直接转为超激化/蔓激化的独立累积，原激元素总量不变。

| 中间产物 | 新触发元素 | 中间产物消耗 | 自由触发元素消耗 | 新增产物数量 |
| --- | --- | ---: | ---: | --- |
| 草原核 `C` | 雷（超绽放） | 全部 `C` | 30G雷 | `Hyperbloom += C + 30G` |
| 草原核 `C` | 火（烈绽放） | 全部 `C` | 30G火 | `Burgeon += C + 30G` |
| 激元素 `Q` | 雷（超激化） | 0G | 30G雷 | `Aggravate += 30G` |
| 激元素 `Q` | 草（蔓激化） | 0G | 30G草 | `Spread += 30G` |

超绽放/烈绽放完成后草原核库存为0；超激化/蔓激化完成后激元素库存仍为`Q`。新生成的四类进阶累积都按稳定终产物处理；没有额外的临时附着池，也不继续拆解原料。

当草原核已累计多个份额时，“全量消耗”指当前参与结算的**草原核总量**，不是只消耗其中30G或保留部分旧草原核。若未来引入有独立实体身份的多个草原核，则需另行确定单次反应影响的实体集合；当前单果结算只使用一个草原核累计量。

以上是水瓜的物质记账规则：原神战斗中的攻击附着量不等于水瓜的原料量，固定每次30G触发量仍属于水瓜自身的设计约束。
### 6.3 高水平培养：预置残留降低后期富集成本

挂果后富集速率随 `M = ΣE_free + ΣProducts` 指数减速，**预先在成熟的90G预算里配置下一段反应需要的元素**，可以缩短到再次跨越>30G触发资格所需的后续增长量：

- 若成熟时某个后续触发元素是 `20G`，且没有在初次成熟被反应消耗，挂果时只需新增 **>10G** 便能跨越30G；不是从0G重新补到>30G。
- 若成熟时该元素仅 `0G`，则需要挂果后新增 **>30G**，总占用必须超过120G；在指数减速下显著更慢。
- 高水平玩家的关键是**保留已经足够接近1U、但初次尚不能主动触发的第三元素**，或利用初次反应后的残留作为下一阶段原料；要谨慎处理首轮反应会吃掉多少预置元素、90G初始可同时主动的只有两个。
- **示例只是可达性差异，不代表第三元素20G一定能成功预置**：必须先通过真实初次成熟反应及其消耗，确保这20G没有被扣减、并确保第一次反应本身能够发生。成熟时两个元素已>30G，第三元素20G可达的总和需要超过80G；剩余额度和消耗都要单独算清。
- 玩家不通过延长挂果无限堆积“七元素全反应”，而是预先安排有方向的最多一到两次后续培养。

**精确示例：靠预置雷来培养超绽放果**（只示范成长门槛，不提前锁定完整绽放消耗表）：

```text
初次成熟90G：水30.5 / 草30.5 / 雷29
→ 水、草均>30G，触发绽放，生成草原核产物
→ 雷29G未达到主动门槛，也没有参与首次水草反应
→ 若保留雷29G，成熟后再富集雷超过1G
→ 雷首次>30G，取得对草原核发动超绽放的资格
→ 此时总占用仅稍高于91G，远低于先养纯水90G、再补足第二元素的>120G路径
```

此路线的实际草原核数量与二次反应消耗比例尚待核定，但**第三种元素在初次成熟时小于30G、随后只需少量新增即可取得新触发资格**，完全由现有门槛与质量守恒推导得出。这里的“高水平”指在总成长预算里预先布局，而不是绕过每次1U投入。


### 6.4 KQM 草元素反应的实际消耗：绽放与原激化（研究核对）

本节区分**原神实验性机制**与**水瓜自己的游戏化消耗记账**。原神的元素量 GU 并不等于果实物质量；本策划仍固定 `1U = 30G`，并取消战斗 20% 附着税。

| 初始反应方向 | 原神元素量消耗 | 水瓜1U触发的原料消耗 | 对应生成物质量 |
| --- | --- | --- | --- |
| 水触发草：弱绽放 | 对草消耗0.5倍触发水 GU | 水30G＋草最多15G | 草原核最多45G |
| 草触发水：强绽放 | 对水消耗2倍触发草 GU | 草30G＋水最多60G | 草原核最多90G |
| 雷触发草：原激化 | 对草消耗1倍触发雷 GU | 雷30G＋草最多30G | 激元素最多60G |
| 草触发雷：原激化 | 对雷消耗1倍触发草 GU | 草30G＋雷最多30G | 激元素最多60G |

- KQM 证据：[Bloom 的2:1（水:草）方向性消耗](https://library.keqingmains.com/combat-mechanics/elemental-effects/transformative-reactions)；[Quicken 的双方1:1消耗及原激化反应](https://library.keqingmains.com/combat-mechanics/elemental-effects/additive-reactions)。
- **初次成熟KQM默认方向**中水优先于草，所以90G初次成熟的水＋草通常为**水触发弱绽放**；后续新增长草作为触发方才可能形成强绽放。不要把绽放“无伤害增幅方向差异”误读为“无元素消耗方向性”。
- 发生反应后，已消耗的双方原料都按**实际消耗**转入同一份草原核／激元素产物，产物不保留可提取的旧水、草、雷。
- 只有草原核及激元素享有下文的限定后续反应权限，不因其原材料中曾含某元素而自动解锁其他普通元素反应。
- 不直接将原神的元素量比例等同于原神草原核实体数量：水瓜当前一个完整离散绽放生成一个具有 `amount` 的草原核产物份额，不复制原神最多五核／六秒爆炸等战斗对象规则。

### 6.5 草原核进阶：全量消耗（已确认）

水瓜草原核对应原神绽放产生的草原核；原神超绽放／烈绽放会将被触发的草原核**整体消耗**。水瓜采用同一全量消耗方向，按已确认的1U规则进行守恒记账。

```text
触发：新增雷（超绽放）或火（烈绽放）取得合法1U资格
C = 当前草原核累计量（C > 0）
Free[触发元素] -= 30G
Core -= C                     // 草原核全量归零
Products[超绽放/烈绽放] += C + 30G
M_after = M_before
```

例子：

```text
成熟前：水30.5 / 草30.5 / 雷29               M=90
水触发弱绽放：水-30、草-15
→ 自由水0.5 / 草15.5 / 雷29 / 草原核45     M=90
挂果补雷1.1 → 雷30.1                     M=91.1
雷触发超绽放：雷-30、草原核-45、超绽放+75
→ 自由水0.5 / 草15.5 / 雷0.1 / 超绽放75   M=91.1
草原核剩余0
```

火触发烈绽放同理。新产物不是45G草原核与30G雷/火的第二份复制，而是消耗双方后新形成的75G稳定终产物。

参考：[KQM Transformative Reactions](https://library.keqingmains.com/combat-mechanics/elemental-effects/transformative-reactions)。
### 6.6 激元素进阶：激元素保留，新增1U转化（已确认）

原神超激化/蔓激化不会消耗既有激元素（Quicken）；水瓜按这一非消耗条件保留激元素，同时把新投入1U直接记入对应的稳定进阶累积，不重复生成激元素。

```text
触发：已有激元素 Q > 0，新增雷／草具有合法1U事件
Free[雷] -= 30G             // 超激化
Products[Aggravate] += 30G  // 直接累计超激化
Quicken.amount = Q           // 原激化部分完全不变

或：

Free[草] -= 30G             // 蔓激化
Products[Spread] += 30G     // 直接累计蔓激化
Quicken.amount = Q           // 原激化部分完全不变

M_after = M_before
```

示例：

```text
成熟前：雷59 / 草31                           M=90
雷触发原激化：雷-30、草-30
→ 自由雷29 / 草1 / 激元素60                  M=90
挂果补雷1.1 → 雷30.1                       M=91.1
雷触发超激化：自由雷-30、激元素消耗0
→ 自由雷0.1 / 草1 / 激元素60 / 超激化累积30  M=91.1
```

蔓激化可使用初始雷31G／草59G，先形成60G激元素并保留草29G，后续补草超过1G触发并积累30G蔓激化。

**同一种进阶产物可以按多次合法事件继续累计，但每次新增必须真实投入新的30G自由雷／草**；同一份已经反应过的30G不能重复贡献。激元素自身不消耗，成熟后总量增长仍受到指数式富集减速限制。合法事件的重复资格规则仍在下一轮处理。

原神Quicken面对水、火可能涉及其它反应；本轮只锁定雷/草触发的超激化/蔓激化数量结算，不提前批准额外路线。

参考：[KQM Additive Reactions](https://library.keqingmains.com/combat-mechanics/elemental-effects/additive-reactions)。
## 7. 剩余数量结算问题（本次不代为决定）

1. **已厘清、待同步旧合同**：花与果实共用同一Growth/物质总量，30G结果、90G成熟；旧Flower/Fruit=100及独立`FruitElementAmount[7]`需同步母叶纤维化、采摘和现有实现。
2. **已解决连续份额下限**：每次完整投入1U=30G；剩余不足1U立即终止当前连续反应。恰好30G的后续事件资格仍需与首次严格>30G的门槛对齐。
3. **待定重复触发资格**：已经>30G的自由元素继续富集，如何定义下一次有效新增1U事件，防止每Tick重复消费旧库存。
4. **已解决草原核进阶**：对草原核累计量全量消耗，加入30G雷/火后形成等质量的超绽放/烈绽放终产物；核库存清零。现行果实采用单草原核累计，若未来引入多个独立实体需再决定对象集合。
5. **已解决激元素进阶**：原激化累计保持不变；新增30G雷/草直接转为30G超激化/蔓激化累积。重复催化须再次投入真实自由元素。
6. **待定其他反应系数与SRP例外**：感电、冻结、燃烧、扩散、结晶、超载等各自真实扣除量、产物量与有限多候选排序；激元素遇水/火等是否增加额外可反应路线。
7. **待定成熟后增长数值**：指数减速常数`k`、是否有硬容量上限`M_cap`、目标挂果时长与离线结算的数值精度。

本文件**不讨论味道、风味倍率、视觉、加工与料理产出**，仅统计自由元素、可反应中间产物和稳定终产物的真实G数量。
