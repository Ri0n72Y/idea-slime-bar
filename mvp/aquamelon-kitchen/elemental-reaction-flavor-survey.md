# 水瓜厨房：元素反应战斗效果 × 风味与口感研究表

> **研究/讨论稿，2026-10-09。尚未确认为玩法 Spec；不授权实现。**
>
> 本文先搜集《原神》真实元素反应的战斗效果，再提出可供逐项讨论的 Aquamelon Kitchen 风味类比。表中**战斗效果是来源所支持的机制事实**，而**口味、质地和融合假设是本项目的创意推导**；两者不能混同。与现有 v0 数值规则冲突时，以 [growth-system.md](growth-system.md) 和 [elemental-cultivation.md](elemental-cultivation.md) 的现行部分为准。

## 1. 目前已有的设计边界

- 正式 v0 果实数据：`FruitElementAmount[7]` 是累计事实；`FlavorRatio[e] = FruitElementAmount[e] / sum(FruitElementAmount)` 是派生的七元素比例，不应直接替换成新的六维 Taste 数值表。成熟后元素比例仍可变化，`Affinity` 已锁定。
- 现有 [elemental-cultivation.md](elemental-cultivation.md) 下半部的六维 `Sweet / Sour / Bitter / Astringent / Fresh / Tingle`、基础值、七元素修正以及旧 `BloomStrength` 是**延后历史草稿**；有参考价值，但不是当前公式。
- 当前确认的元素反应型水瓜概念仅为 **水 + 草 → 绽放（草原核 / 草种子性状体）**，而非果实在世界中执行《原神》战斗技能。其余反应均是**研究候选**，不是已批准的果实类型、配方或生产规则。
- 单元素朝自身风味方向拓展；反应不应凭空创造与原料无关的主味。反应可改变 **两味的衔接/融合、香气释放的方式、风味强弱的时间曲线，以及组织/口感**。
- 草原核果实可与普通水草混合果实**味型差距不大**：它真正的独特性在更协调、较少生涩、可辨认的柔软种子状组织和入口的轻微破裂反馈。
- 战斗中同样的两元素也可能因**施加顺序、元素量、残留附着和后续第三元素**产生差异。不要把“看见两种元素”直接等同于“生成对应特殊材料”。

### 单元素方向：沿用旧六维 Taste 草稿的定性归纳（非正式数值）

| 元素 | 已有草稿方向 | 可继续延展的感官母题（建议，非锁定） |
| --- | --- | --- |
| 火 Pyro | 刺激↑、清爽↓；少量甜/苦 | 温热、辛香、焙烤；强烈不等于一定更甜 |
| 水 Hydro | 清爽↑、清甜↑、苦涩↓ | 多汁、稀释感、轻盈、柔润 |
| 风 Anemo | 清爽↑、酸↑、轻微刺激 | 扬香、通透、轻薄、扩散快 |
| 雷 Electro | 酸↑、刺激↑、甜略降 | 跳跃酸感、舌尖微麻、脉冲/跳跳糖 |
| 草 Dendro | 苦涩↑、植物清鲜↑ | 青绿、草本、纤维、青草尾韵 |
| 冰 Cryo | 清爽↑、轻酸甜 | 冷感、清脆、洁净、释放速度慢 |
| 岩 Geo | 涩/苦↑、清爽略降 | 矿物感、紧实、厚重、脆壳/颗粒 |

这是一份语义速记，不是让 `FlavorRatio` 额外持久化七套口味，也不是给所有反应先设固定数值。

## 2. 从「高等元素论」借用什么？

原先《高等元素论》及后续 KQM 的 Elemental Gauge Theory 所讨论的是**附着、触发、元素量消耗、残留、反应顺序与复合反应**，而不仅是“两个元素对应一个反应名” [S1][S2][S3]。

对口味设计更有价值的是把战斗效果区分成几种形态：

| 战斗效果结构 | 对感官设计的启发 | 应避免的误读 |
| --- | --- | --- |
| 增幅（蒸发/融化） | 放大原来的某种味觉、改变前中后调，不必产生新组织 | 2 倍伤害 ≠ 2 倍甜度 |
| 独立持续/范围伤害（感电、燃烧、超载等） | 余韵、脉冲、爆发、扩散速度、颗粒破裂方式 | 火伤害 ≠ 食物一定灼烧人体 |
| 状态/辅助（冻结、原激化、超导、结晶） | 口感锁定、后续释放、调和、包裹保护或易感性 | 没有战斗伤害 ≠ 没有食用特色 |
| 创造物与二段反应（绽放、超绽放、烈绽放、部分月/星反应） | 胶核、包埋、递延释放、被第三元素催化后的质地质变 | 草原核不是现实可食种子；不能直接复制爆炸伤害 |
| 传播/共同参与（扩散、月/星特化） | 香气空间感、口味均匀性、叠层与和声 | 玩家角色限定触发机制 ≠ 普通双元素果实自动触发 |

## 3. 经典元素反应：战斗机制与味觉候选

表内 **F** = 经资料核实的《原神》战斗效果；**D** = 尚待 Lead 讨论的水瓜风味、口感设计假设。均未制定触发阈值与数值。

| 反应 | 元素/前提 | F：战斗实际效果 | D：味道与融合方向（候选） | D：质地/口感辨识点（候选） |
| --- | --- | --- | --- | --- |
| **蒸发** | 火 + 水；施加顺序影响增幅倍率 | **增幅**触发攻击：后手水 2×；后手火 1.5×，不额外独立攻击 [S3][S4] | 火香气与水清甜被提亮，清爽感不被完全削弱；偏水侧可更轻盈，偏火侧可更浓香 | 水汽般的扬香、轻泡或入口即散；**非**字面上会烫嘴 |
| **融化** | 火 + 冰；顺序影响倍率 | **增幅**：后手火 2×；后手冰 1.5× [S3][S4] | 冰的清冷酸甜与火的温辛相互软化，味道由分层向浓润过渡 | 从清脆/冻感向柔滑融开的过渡，融化过程本身成为特色 |
| **超载** | 火 + 雷 | 产生额外**火元素范围爆炸**，强削韧/击退，能破坏坚硬物 [S3][S4] | 雷酸与火辛依然鲜明，融合未必更好，优势是瞬间强烈、短促有力 | 爆珠/跳跳糖式突发脆响；强烈冲击后快速退去 |
| **感电** | 水 + 雷 | **雷伤持续触发**，对附近带水目标可间歇传播；水、雷可共存一段时间 [S3][S4] | 水的清爽作为雷酸、舌尖刺激的载体，味道以一阵阵节奏出现，而非一次释放完 | 细密气泡、连续轻麻、逐次释放；区别于超载的一次爆裂 |
| **超导** | 冰 + 雷 | **冰元素范围伤害**，使目标物理抗性降低（常规为 40%，12 秒）[S3][S4] | 冰的低温净感与雷的微酸/刺激形成轻微麻凉，后续味道仿佛更容易感知 | 细凉而不坚硬、微麻后回甘；不是“伤害更大”的味型 |
| **冻结** | 水 + 冰 | 施加冻结状态，限制行动；后续重击可造成碎冰 [S3][S4] | 水的清甜被低温收束，入口先平静，解冻后慢慢开放 | 冻凝、冰沙或冷润胶冻；有延迟释放的阶段感 |
| **碎冰** | 已冻结 + 钝击/岩攻击等 | **解除冻结并造成额外物理伤害**，是冻结后的二段结果，不是普通新双元素配对 [S3][S4] | 与冻结同一基础味型，破裂时才突然释放被封存的清甜与酸香 | 冻壳脆裂、脆粒和融液同时出现，层次鲜明 |
| **扩散** | 风触发已附着的火/水/雷/冰 | 产生对应元素的扩散伤害，并**传播该元素附着**，可能在其他目标上触发次级反应；与元素染色不同 [S2][S3] | 并非简单增强味强：令原有火香、水清、雷酸、冰凉更均匀地散布到鼻腔和口腔 | 轻盈、蓬松、挥发快；偏“香气传播/均匀性”，不必凭空多出新味 |
| **结晶** | 岩触发火/水/雷/冰附着 | 产生对应属性的**晶片**，拾取给予结晶护盾；一般不直接造成反应伤害 [S3][S4] | 将某种主味包裹、保存，降低尖锐度；食用时核心味被分段释放 | 可咬破的晶壳/矿物砂糖外衣，外硬内软，带防护/封存感 |
| **燃烧** | 草 + 火 | 产生**持续火元素伤害**，能持续产生火附着 [S3][S5] | 草本青苦转向焙香、烘烤与轻烟熏；并非单纯更辣，更强调持续的焦香尾调 | 较干、略焦脆、余热和长尾；需考虑可口性，避免实际烧焦不适 |
| **原激化** | 草 + 雷 | 创建特殊**激化附着/状态**，本次反应无额外伤害，随后可触发超激化/蔓激化 [S3][S5] | 像“被唤醒”的草本和电酸，主味未必大变，但后续风味更易被引出 | 蓄势的细微麻感、入口前段平缓，尾韵带可被激发的层次 |
| **超激化** | 激化状态 + 雷 | 后续**雷元素攻击获得额外基础伤害加成**（加算），不是独立雷爆炸 [S3][S5] | 保留草雷底味，把雷的亮酸、微麻和跳跃感推到前景 | 舌尖细密闪烁、短促清脆；与原激化的“蓄势”有别 |
| **蔓激化** | 激化状态 + 草 | 后续**草元素攻击获得额外基础伤害加成**（加算）[S3][S5] | 雷刺激成为衬底，草本清香、鲜绿和余韵变得更繁复、更悠长 | 纤维或柔软组织更丰厚，香气慢慢舒展；不等于机械减苦 |
| **绽放** | 水 + 草 | 产生**草原核**；积累到数量上限或经过一定时间会爆裂，造成草元素范围伤害；核可继续接受雷/火反应 [S3][S5] | **核心提案**：普通水草味仍在，但清甜/青绿衔接更顺，草的苦涩被缓和，清爽更统一；不必显著偏离水草基底 | 果肉/汁液中出现柔软的种子状胶核，咬开时轻微“啵”感、鲜汁融合；反应型独特组织比单纯加糖重要 |
| **超绽放** | 已存在草原核 + 雷 | 草原核被雷激活后变为**自动追踪目标的蔓生弹**，造成集中的草元素伤害 [S3][S5] | 保留绽放已调和的水草基底，雷的微酸与刺激以“定点爆点”形式突然出现 | 不同于绽放的软胶核：小颗粒受咬压后精准迸汁，持续时间短而集中 |
| **烈绽放** | 已存在草原核 + 火 | 草原核遇火会**瞬时产生更强的草元素范围爆裂伤害** [S3][S5] | 保留水草基底但加入焙香与温辛，冲击更广、更猛烈；较超绽放不必强调酸 | 胀裂的果粒/轻爆浆，余韵偏暖，范围感和爆开感强于普通绽放 |

说明：

- **冻结 → 碎冰**、**原激化 → 超/蔓激化**、**绽放 → 超/烈绽放**是**有前置状态/实体的二段结构**，不能直接简化为三元素同时超过同一个百分比阈值。
- 风和岩的常规反应主要作用于火/水/雷/冰；**风 + 草、岩 + 草、风 + 岩**在普通条件下不是本表这种标准双元素反应。不能为了填满七元素两两矩阵而发明原作反应。
- 蒸发、融化存在先后手差异；口味是否也需要顺序差异，**尚未决定**。目前只给出可讨论的感官提示。

## 4. 后续版本的特殊反应（仅创意参考，非现有 MVP 内容）

截至此次整理，《原神》还存在在**指定角色机制/队伍条件**下替代普通反应的月曜、星烁系列。它们不是两种元素相遇必然会发生的基础反应 [S3][S6][S7]。

| 特殊反应 | 元素与额外前提 | F：战斗实际效果 | D：可以借鉴的风味 / 口感母题 |
| --- | --- | --- | --- |
| **月感电** | 水 + 雷；需要对应月兆角色赋能 | 形成**雷暴云**，持续协同打击，可根据多个参与者的附着贡献结算，特殊伤害可暴击 [S3][S6] | 与普通感电的独奏脉冲相对：多个清爽与电酸音符持续交织，细泡层层叠加、节奏更顺 |
| **月绽放** | 水 + 草；需要对应月兆角色赋能 | 绽放仍形成草原核，额外生成可被特定技能消耗的**草露资源**；仅触发本身不等于直接造成月绽放伤害 [S3][S6] | 在普通绽放协调水草的基础上，突出“草露”般润泽、晶莹与更绵长的清甜；应区别于简单加强甜度 |
| **月结晶** | 水 + 岩；需要对应月兆角色赋能 | 原本的水岩结晶可被替代为产生**月笼**，多次触发后共鸣攻击；并非普通结晶盾效果 [S3][S6] | 水润在岩质包裹中形成节奏性释放的共鸣层：晶莹、清亮、脆壳包着连续汁感 |
| **星超导** | 冰 + 雷；需要星烁机制赋能 | 产生**极星辉域/棱晶**，连续冰雷附着积累强化效果；本反应不直接造成常规独立反应伤害 [S7] | 与普通超导的“麻凉”不同：冰凉和微麻随咀嚼层层加深，仿佛舌面形成持续增强的冷感区域 |
| **星扩散** | 冰 + 风；需要星烁机制赋能 | 替代特定冰扩散，生成**星辉风旋**；反复触发使之升级，随后延迟爆发范围冰伤，并附带高跳等效果 [S7][S8] | 冰风的轻盈香气先浮起，蓬松泡沫聚集后转为骤然清冽的冰晶破裂；强调“积聚 → 延迟绽裂” |

不把角色天赋依赖、暴击计算或战斗伤害倍率照搬为料理与果实系统，也不把上述特殊反应默认算作普通果实“下一层升级”。

## 5. 第一轮重点：绽放草原核 vs. 普通水草混合

这是目前**唯一应优先推进的反应果实概念**。此处特别避免把“反应”定义成比混合更甜、更高质量的简单数值增益。

| 对照 | 风味核心 | 融合程度 | 组织/口感 | 观察目的 |
| --- | --- | --- | --- | --- |
| **纯水偏向果实** | 水的清甜、清爽、多汁 | 无两元素融合课题 | 汁液更清润 | 水的基准 |
| **纯草偏向果实** | 青绿植物香、少量苦涩和纤维感 | 无两元素融合课题 | 植物性组织更鲜明 | 草的基准 |
| **普通水草混合果实**（未反应） | 同时尝到水的清甜和草的青绿，前后调可能分离 | 有混合，但衔接可生硬 | 普通果肉/汁液 | 与反应果实的关键对照组 |
| **绽放草原核果实**（候选） | 仍是水草味；青绿苦涩更圆润，清甜与草香融为同一段连续味 | **显著更协调，而不是无限叠甜** | **细软种子状胶核**，轻咬即破，释放与基底同调的鲜汁 | 验证“同样原料，多了反应后有可感知质变” |

既有旧稿参考：水草绽放曾预设“甜 +15、苦 -8、涩 -10、清爽 +20”和可辨认的草种子性状体；该固定修正及 `BloomStrength` **目前不作为现行数据合同**。我们要保留它希望达到的**降低草的生涩、提高融合、改变口感**这一意图，再讨论是否需要另立新算法。

尤其区分：

1. **水草一起富集**：属于七元素比例事实，`FlavorRatio` 能表达。
2. **绽放带来的“反应发生”**：涉及是否产生新的性状体和风味结构，目前没有批准的新状态/触发算法。
3. **高等元素论启发的次级反应**：草原核遇雷/火产生另一个结果，但**不等于**三元素水瓜会自动成为超绽放/烈绽放果实。需要分别设计触发顺序与组织承载边界。

## 6. 下一轮逐个讨论的顺序（建议）

先讨论 **① 绽放（核心）**：只固定味觉变化的方向与口感特性，不急于设计数值公式；再讨论 **② 原激化 / 超激化 / 蔓激化**（增益是“激发潜能”而非爆炸）；**③ 感电 / 超载 / 超导**（跳跃、爆发、麻凉如何区分）；**④ 蒸发 / 融化 / 冻结 / 碎冰**（物理过程和释放顺序）；**⑤ 扩散 / 结晶 / 燃烧**（传播、包裹、烘焙）；最后才讨论月曜、星烁的**可否借鉴**，并非默认纳入玩法。

每个反应至少回答以下五件事：单元素本味保留多少、两个味道是并存还是融合、风味的释放先后、质地/咀嚼变化、是连续存在的果实性状还是加工后才发生。确认以后再决定数据表示与触发条件，且不要擅自修改当前 `FruitElementAmount / FlavorRatio` 权威语义。
