## 1. 最小可复核验收

- [ ] 纯 Lua 单机从铺土、播种到熟果→采摘→唯一果汁→完整提示词走通；不调用服务器节点图。
- [ ] 以两条不同合法元素输入路线形成不同真实原料/反应数据；差异可以逐项解释。
- [ ] Seed 45G 不清零，90G 逐维结转 Reserve 且当场产生首 Bud。
- [ ] Bud 20G、SmallLeaf 26G、同步 LargeLeaf+FlowerBud、生殖12/40/90G 及亲和固化按事件正确发生。
- [ ] Sapling每步从本次根系吸收后的真实Reserve计算`R`，`B_ref=B0×F_growth(R)×Δuh`，逐维按`min(Reserve[i],B_ref/7×max(0,TreeEffectiveAffinity[i]))`形成动态V预算；`/7`是七维数量，不表示固定7V。验证低/中/高Reserve、缺元素、不同亲和与分数uh，且不强制将ΣBudget归一化或跨元素补偿。
- [ ] 每叶取得树动态Budget的30%，花果只从母叶分流，未用V返还；Tree/Bud的实际V直接累加Growth，不再乘Tree Affinity；其他器官使用自身生长规则，环境逸散独立记账且不返还。
- [ ] 熟果 Stage 锁存；普通产物守恒、风扩散允许净变化；合法感电共存按雷→水检查双扩散严格门槛，剩余风不可重复使用；无负库存。
- [ ] 新反应只允许本次真实自然Growth新增元素担任主动方，且其当前自由量严格>30G；旧库存即使>30G也不借新增的被动元素触发。验证「已有水60G、雷由10G增至12G」不能首次启动感电（虽然双方首轮各12G足额）；首次合法启动仍须双方各12G，启动后周期尾次可不足额。
- [ ] 成熟后的风扩散只由本次新增且严格>30G的自由风触发；仅新增长扩散源至15G、旧风充足不得反向触发。燃烧合法启动当次消耗最多12G草而不扣火；合法普通反应在同事件即时结算，有限SRP竞争、进阶及同一主动方的足额连锁无无限循环。
- [ ] 单球固定50V、七元素等概率，0.25uh半衰和<1V销毁准确；点击收集时根据真实剩余量进入 Soil。
- [ ] 普通 UI 的 Growth、目标及可信 G/uh 正确，未满窗口显示“采样中”，Debug 精确量不在普通状态/提示中泄漏。
- [ ] Lua 对器官按 BaseAffinity 底色+Growth 七维归一混色叠加30%，无元素阈值；**首次生成的反应产物锁定果实整图标/名称**，后续多反应不换图；残留 E_free 混色叠加30%。
- [ ] 熟果材料删除、唯一果汁生成、`E_free/Products` 全额无复制转移。
- [ ] 多重反应的果实仍保持首次产物外形；AI 品尝包含其他**当前真实存在的**反应产物风味，产物被进阶消耗时不重复计味；单纯风扩散不锁定产物外形。
- [ ] 冻结产物以冰块呈现；燃烧体现草生发被火激活的持续活跃热感，与超载的瞬时爆炸刺激区分。
- [ ] 提示词包含全部七元素（含0值）、全部产物、事实/想象分界和入口/中段/回味说明；首尾无截断。
- [ ] 如果没有可靠剪贴板复制，采用实际可阅读/逐页截图交付，不声称“复制通过”。

## 2. 已决定但不可误读

- **1uh=10秒**只改变现实播放速度，不改 V/uh、G/uh 的物理模型。
- **一份熟瓜→一份果汁**完整转移果实账本，不产出需分账副产物。
- **风味**：按七元素感官与当前反应产物解释；提示词包含自由量、产物组成和已确定的描述，入口/中段/回味作为叙述顺序。
- **感电首次启动**：本次新增主动元素须严格>30G，且水雷双方首轮各至少12G；已有另一方>30G不能替代新加入但不足资格的元素主动触发。已启动之后允许不足额尾次。
- **普通反应**：本次新增元素满足主动门槛才在当事件立即结算；同一合法主动方允许足额连锁，不能由旧被动库存换手继续主动；无Growth的空Tick不重复扣费。
- **首次产物定形**：首个实际产生的反应产物锁定果实名称/图标，后续反应只增改实际风味与账本，不改外观；扩散无独立产物，不占首产物身份。
- **冻结/燃烧感官**：冻结按冰块处理；燃烧为草生发被火激活的活跃热感，非超载瞬间爆裂。
