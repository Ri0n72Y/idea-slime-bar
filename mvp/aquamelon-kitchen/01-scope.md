# 参赛范围

## P0：必须完成

1. 从铺土、播种到成熟水瓜的真实生命周期，含 Growth、Affinity 遗传与器官分流。
2. 玩家主动「富集」随机元素球，选择「收集」并改变土壤供给；球真实衰减。
3. 成熟前后按已确定的七元素物质账户与反应规则结算；展示有依据的颜色/图标暗示。
4. 一次采摘成熟果形成独立材料；**一份成熟水瓜直接转为唯一一份水瓜汁**。
5. 由真实果汁数据生成自包含中文 AI 品尝提示词，并可完整交给玩家自行选用的外部对话 AI。
6. 普通界面显示对象、阶段、真实总 G、合法目标、可信 G/uh；Debug 才显示内部七维数据。
7. 单机自然推进与 Debug 快进共用同一套 Lua 结算；完成两种元素路线的端到端验收。

## P1：仅 P0 完成后

1. 将文本占位和图标进一步替换为像素画。
2. 增加放大镜工具：点选土壤、树干、叶、果等，在底部状态栏显示可观察描述。
3. 增加手套工具：按对象真实收获资格执行采摘。
4. P1 不增加新的 Growth、遗传、材料或反应公式。

## 明确不做

- 服务端节点图、多人、网络 API、游戏内调用 AI、正式顾客与经营系统。
- 完整料理配方、背包堆叠、自动富集与自动收集。
- P0 所需之外的多步骤果壳/果肉加工；存档、跨日离线补算、未来扩展框架。
- 独立的第二份游戏权威状态、ECS/事件总线等为未来多人预留的复杂结构。

## 实施底线

- 操作成功/失败由游戏数据确定；UI 只发出动作并展示结果。
- UI 和 Debug 绝不为便利而改写培养数值。
- 参赛 P0 结束条件是**真实果汁提示词可完整交付**，不是美术精细程度。
