# 元素反应数值合同（参赛 Demo）

本文件直接定义果实自由元素、反应产物、触发资格与结算顺序。

## 1. 账户与资格

- 反应首次检查在 **90G 初次成熟**事件；成熟后只有合法真实 Growth 输入或持续反应计时能再次引发结算。
- `1U = 30G`；普通非风反应的主动元素须**严格 >30G**，恰好30G不能主动启动。成熟后的每次新反应必须由**本次真实自然Growth新增的元素本身**担任主动方；已有元素即使自由库存>30G，也只能按合法方向作为被动方，不能代替本次新增元素触发。小份Growth可以先累积自由库存，但本次新增元素在结算后仍未严格超过30G时，没有足额主动附着资格。
- 普通一次性反应只投入主动元素 30G；被动目标必须有该方向完整配额，不足额则双方均不扣、不产生残次产物。
- 普通守恒反应产物质量 = 本次双方真实扣费之和；产物进入 `Products[]`，退出 `E_free[7]`。
- 成熟阶段为锁定状态，不因反应扣量、风扩散总量净减或新富集而回退。
- **初次成熟事件**如可明确本次真实新增的元素，也只检查该新增元素的主动资格；只有无法区分新增先后的初次成熟或同批多个真实新增元素，才在这些**实际新增候选**中按 **雷 > 火 > 风 > 冰 > 水 > 草 > 岩** 排序。冻结不是自由元素，不是候选触发方。**本次新增风且满足合法扩散时先于普通反应**；普通反应的同触发方竞争再按照§5的有限SRP判定。

## 3. 持续反应和特殊进阶

| 反应 | 每次原料扣减 | 产物 | 条件 |
| --- | --- | --- | --- |
| 感电（水＋雷） | 首轮立即双方各扣12G；此后每完整uh双方最多各12G，尾次取两者较小剩量`d` | 感电`2d` | 合法>30G主动方且双方均有首轮12G时启动；任一方为0停止 |
| 燃烧（火＋草） | **启动当次**先扣`min(12G,草当前自由量)`；此后每完整uh最多扣草12G；火不扣 | 燃烧=实际扣草量 | 本次存在合法>30G主动方且火>0、草>0；火或草为0停止 |
| 超绽放 | 新有效雷30G + **全部现有草原核 C** | 稳定超绽放 `30+C` | 核归零 |
| 烈绽放 | 新有效火30G + **全部现有草原核 C** | 稳定烈绽放 `30+C` | 核归零 |
| 超激化 | 新有效雷30G | 稳定超激化30G | 激元素 Q 保留，不另扣 Q |
| 蔓激化 | 新有效草30G | 稳定蔓激化30G | 激元素 Q 保留，不另扣 Q |

**感电首次启动同时满足两类资格**：双方自由量均不少于首轮12G，且**本次真实新增的主动元素自身严格>30G**；不能把「首轮可扣12G」误当作「新附着具有1U主动资格」。例如原有自由水60G、雷10G，本次新增雷使其达到12G，虽然双方均有12G可扣，但雷不足主动资格，**不启动、不扣费**；已有的水60G不能替代雷当触发方。感电成功启动之后的定时持续扣费才允许不足12G的尾次，不需要每个周期重新获得新主动附着。

**燃烧的首轮**也在合法启动事件内立即结算，但不同于感电：首次草自由量不足12G时照实际剩余量扣草，不需要双方12G齐备；火是触发与维持条件，不扣除自由火。持续状态只记录是否活动与下一合法周期，不是新增物质量。

**普通合法反应在同一个真实 Growth/成熟事件立即结算**，不得人为等待下一 uh；满足余量与方向条件时当事件内可继续下一次完整反应。示例：火70G、水30G，合法方向下火逆蒸发可执行两次，产物合计90G，火剩10G、水剩0G；空 Tick 不再次扣旧库存。持续感电/燃烧的后续仍按 uh 计时，不能跟随帧刷新无限连锁。

## 4. 风扩散（独立于普通守恒反应）

- 只有自由火/水/雷/冰可作为扩散源；**稳定冻结、结晶及其他稳定 Products 不可扩散**。
- 风必须自由量严格 `>30G`，源自由元素至少 `15G`；每个合法事件合并本次所有完整1U风份额，最低单源实际扣费量子为0.5U。
- 首次成熟仅按§1的真实新增触发元素规则检查；成熟后只有**本次真实新增风元素**，且自由风在入账后严格`>30G`并存在至少15G合格自由源时，才能启动新的风扩散。若本次仅新增火/水/雷/冰并令扩散源跨过15G，已有风即使足量也**不能替新增源反向触发风扩散**。
- 一个真实 Growth 批次最多**一次合并风扩散事件**；同批多元素跨线也不能多次使用同一份风；风扩散新生成的自由元素不可在同一事件重入扩散。
- **双扩散仅允许已经启动且仍有自由水、雷的感电活动共存**：先雷后水，冻结是稳定产物、不使用冻结双扩散。普通自由水+雷并存不等于活动共存，更不能使同一份风重复生成两次全量传播。
- 令本次合并风强度`W_event=floor(E_free[风]/30G)`（U），雷段输入`A_e=E_free[雷]/30G`（U）；只有`0.5×W_event > 0.8×A_e`**严格成立**，冻结快照中的雷在实际量子扣除后、**尚未传播回填之前已完全耗尽**（没有任何雷的自由零头），且还有`W_remaining≥1U`、自由水至少`0.5U`，才可进入**第二段水扩散**。任一条件不满足则只有第一段雷扩散；相等不算双扩散，剩余雷零头也会阻止第二段。
- 第二段`d`、`A_source`、`gain_U`用§4相同公式及**上段扣除后的剩余风**重算，各段至多生成一次传播；两段合计扣风不得超过原始`W_event`。**源是否耗尽与第二段资格只能看传播前冻结的源扣费状态**，不能让第一段回填后的同种元素伪装成尚未扣清的原Aura。传播的新自由元素绝不在本事件内成为新的扩散段输入。
- 边界例：已有合法活动感电共存，风60G、自由雷15G、自由水15G时，雷段量子扣雷15G、风30G，传播后才回填雷；原雷源份额已耗尽且余风30G，因此可以再扣原自由水15G和余风30G，作一段水扩散。若初始雷20G，先扣雷15G会留下5G自由雷零头，**即使风仍剩30G也不进入第二段水扩散**。
- 风源目标优先顺序为 **雷→火→水→冰**；不得和普通反应触发元素默认方向混用。

**已确认数值公式（以 U 为单位）：**

1. `W_event = floor(E_free[风] / 30G)`，本次可用的完整风 U 份额；后续以其剩余量 `W_remaining` 计算。
2. `A_free = E_free[目标] / 30G`，`A_source = 0.8 × A_free`（**源端**0.8税用于传播计算）。
3. `d = 0.5 × floor(min(A_free, 0.5×W_remaining)/0.5)`，只有 `d≥0.5U` 才能本段扩散。
4. `wind_spent = 2d`；`R = W_remaining`（若 `A_source ≥ 0.5×W_remaining`），否则 `R = A_source`。
5. `gain_U = 0.8 × [1 + 1.25×(R−0.04)]`（**传播端**0.8税）。
6. 实际扣风 `wind_spent×30G`，自由目标净变 `(+gain_U−d)×30G`；**没有** `Products[Swirl]`。
7. 同一源元素本段只计算一次传播固定项；多源合法双扩散仍共用本次风预算，不能复制风。

风扩散**可以净增或净减物质量**，这是特设例外；不会产生单独“扩散果实/扩散产物”。

## 5. 同一事件的有限 SRP 与结算顺序

**只对本游戏存在的自由七元素、草原核、激元素及已启动感电状态排序**；以下表格是当前支持反应的优先次序，不引入原神额外的伤害、Frozen Aura、碎冰或其它隐藏状态。

| 本次真正触发的元素 | 其自身满足足额条件的候选，按先后尝试 |
| --- | --- |
| 火 | 烈绽放 → 超载 → 逆蒸发 → 正融化 → 燃烧 |
| 水 | 正蒸发 → 冻结 → 绽放 → 感电 |
| 草 | 蔓激化 → 原激化 → 燃烧 → 绽放 |
| 雷 | 超绽放 → 超激化 → 超载 → 感电 → 超导 → 原激化 |
| 冰 | 超导 → 逆融化 → 冻结 |
| 岩 | 雷结晶 → 火结晶 → 水结晶 → 冰结晶 |
| 风 | 按§4的**雷→火→水→冰**先检查合法扩散，最多一次合并事件 |

- **真实新增Growth若能区分先后**，只有新增元素可担任本次触发方，且入账后的该元素自由库存须严格`>30G`；其他自由元素无论库存多高，均不能借本次事件担任主动方。初次成熟/同批确实无法分辨先后的情形，仅从本批实际新增且具备主动资格的元素中依§1顺序筛选，再按本节同触发方表尝试第一个**合法且原料足额**反应。
- 活动感电水雷共存遭遇第三元素时，**优先消耗雷对应的反应**，例如新增冰时先超导，冰有完整剩余配额才可能再冻结；不要让同一个30G触发投入无条件重复用于第二反应。
- `Products[草原核]`、`Products[激元素]`进阶由表中的合法候选处理；草原核进阶消耗全部核、激元素催化不扣原有激元素。已变成稳定产物的量不可再作为自由被动目标。
- 一次性反应每次都重新检查**本事件已有的合法新增主动方**是否仍严格`>30G`、被动目标配额是否完整；有余量时同一主动方可在本事件内连续执行完整扣费，不能把消耗后仍充足的**旧被动元素**改判为本次新主动方。不同新增主动方按本批既定次序分别检查。任何反应不得生成负量，UI刷新和无新Growth的空Tick不得重新激活一次性反应；没有合法主动输入就不反应。

1. 先输入真实自然Growth、判断首次成熟与原料先后事实。
2. 符合资格时先结算**至多一次合并风扩散**，内部只有符合§4规则才允许感电双扩散第二段。
3. 仅以本次新附着且通过严格>30G门槛的元素为主动方，对最新自由物质及有效产物按本节SRP尝试普通反应、进阶和持续状态的首次启动；每次立即更新库存，并只复查本事件已有主动方的剩余资格，不能改由旧被动库存主动。
4. 已经活动的感电/燃烧后续按真正经过的完整uh周期独立扣费；首次活动在启动当次扣第一轮，不会因为同时遇到定时结算重复扣两次。
5. 写入`E_free + Products`及活动状态、首产物外形标记；UI刷新或没有真实自然Growth的空Tick不重入一次性反应。

**外观事件与反应结算解耦：**首次成功形成非零 `Products[]` 产物的事件将该产物类型/方向记为该果实的首反应形态身份；同事件按现有结算先后顺序判定。后续反应可更新 `Products[]` 和风味，但不改首反应形态。风扩散只改变自由元素且不生成产物，故不会单独锁定产物形态。该标记不影响物质量、SRP或反应资格。

## 6. 结算边界

- 成熟后的**自然富集**按`0.5×clamp((150−M)/60,0,1)`计算；150G不是物质容量上限，扩散的实际净增/净减照账本保留，不做产物溢出销毁。
- 无法由§2～§5建立合法关系的组合不反应；不能把未经定义的原神附着/伤害机制混入本游戏。采摘后终止持续反应，保留采摘瞬间现存自由元素与产物。
- 多反应与一次性事件的实际顺序须以合法输入、SRP和单次扣费更新库存检验，不能凭元素颜色、UI显示顺序或反应图标倒推反应次序。
