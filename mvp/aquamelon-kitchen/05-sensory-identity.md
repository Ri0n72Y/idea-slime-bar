# 七元素感官身份与反应口感

> 本页固定**感官语义与已确认的反应表现**，不创造元素量→味觉强度的计算公式。原料数量与扣费见 [04-elemental-reactions.md](04-elemental-reactions.md)。

## 1. 水瓜基础味道

普通水瓜汁近似**甜味极淡的椰子水**：清爽、柔和、略有植物微甘，比纯水更有饮用满足感；它不是七元素与五种基本味道一一对应的调味剂。

具体甜、酸、薄荷凉、花香、菌菇鲜香应来自对应原料及实际已定义内容，不由某个元素自动赋予。

## 2. 七元素主要作用

| 元素 | 已确认方向 | 具体边界 |
| --- | --- | --- |
| 水 Hydro | **清润** | 清冽、通透、润泽；不是糖分、薄荷凉或海鲜味 |
| 火 Pyro | **热灼** | 温暖至如烈酒入口灼热的非实际温度口感；不是酒精、辣椒、烟熏或真加热 |
| 冰 Cryo | **平抑** | 调和/压低风味峰值、起伏及释放；适量平稳，极端可能压住味道；不是物理冰镇 |
| 岩 Geo | **凝聚** | 原有液体变得有序、胶质、弹性或晶质结构；不是咸味或自动矿物味 |
| 雷 Electro | **活跃度** | 跳动、麻刺或爆裂式刺激的活动性；不是一定有真实气体、放电或固定酸味 |
| 草 Dendro | **丰盈感** | 已有风味的充实、舒展与持续发展；不是自动提高甜、鲜、香浓度 |
| 风 Anemo | **嗅觉扩散；纯风为萦绕感** | 释放与传播已有香气，纯风由舌尖扩展、轻柔环绕再自然消散；不是自动花香、薄荷凉、酒精或气泡 |

注意：冰的平抑与草的风味发展、风的空间萦绕分别是不同作用；岩组织定形也不等同于冰抑制释放。

## 3. 已确认反应的主要感官意向

| 反应／方向 | 感官及形态 |
| --- | --- |
| 水触发蒸发 | **清冽水瓜**：清润更鲜明、温润柔和，不自动增加糖度 |
| 火触发蒸发 | **温灼水瓜**：温暖至灼热，灼感退去后呈现水瓜微甘 |
| 火触发融化 | **炽灼水瓜**：同类火热灼、较高增幅潜力，不另造姜辣或烘烤味 |
| 冰触发融化 | **凝味水瓜**：既有风味被平抑、趋于持久，极端可能过度寡淡 |
| 水＋雷 · 感电 | 连续、反复细麻，类似不含真实气泡的气泡水 |
| 火＋雷 · 超载 | 入口瞬间强烈爆裂，近似“辣”的集中刺激，但不是辣椒味 |
| 冰＋雷 · 超导 | 均匀、细密、绵长酥麻，并使**已有风味更容易被辨认**；不增加真实甜酸量 |
| 水＋冰 · 冻结 | **冰块**：冻结产物直接作为真实可辨的冰块处理，表现冰块的冰凉与冰质口感；不另创造复杂风味，不等同于纯冰元素对其他味道的“平抑”作用 |
| 水＋岩 · 结晶 | 滑润、柔弹的可食水晶胶冻 |
| 火＋岩 · 结晶 | 弹热、回弹明显的可食水晶胶冻 |
| 冰＋岩 · 结晶 | 干净清脆、易断裂的可食水晶胶冻 |
| 雷＋岩 · 结晶 | 咀嚼中如跳跳糖般噼啪；爆裂来自雷，结构来自岩，不要求真实气泡 |
| 水＋草 · 绽放 | 无硬籽石榴式的许多果粒，像葡萄般柔软多汁，咀嚼温和释放风味 |
| 草原核＋雷 · 超绽放 | 弹性绿色果粒，越嚼越释放原有风味；不等于雷岩噼啪爆裂 |
| 草原核＋火 · 烈绽放 | 入口即破的爆珠，原有风味强烈前置，随后迅速回落 |
| 雷＋草 · 原激化 | 原料已有鲜香潜力苏醒，不保证更美味 |
| 激元素＋雷 · 超激化 | 已有鲜香更快、更活跃地展开 |
| 激元素＋草 · 蔓激化 | 已有丰盈继续发展，余韵更绵长 |
| 风＋水/火/冰/雷 · 扩散 | 使参与元素/材料**已有香气**更容易释放或传播；不自动生成特定香型 |
| 火＋草 · 燃烧 | **生发被火激活的活跃热感**：草的生发/丰盈感在火作用下更活跃、温热而持续；不是火雷超载的瞬间爆炸热，也不自动添加焦糊、烟熏或辣椒味 |

## 4. 不能混淆的四对机制

- **超导 vs 原激化**：超导是品尝者更易辨认既有风味；激化是材料自身潜在风味的发展。
- **超载 vs 烈绽放 vs 燃烧**：超载是口腔刺激瞬间爆发；烈绽放是果粒破裂导致味道集中释放；燃烧是草生发被火激活后的持续活跃热感。
- **草原核 vs 岩结晶**：前者是新生植物果粒；后者是液体/内容物有序凝聚。
- **风扩散 vs 雷活跃**：风改变嗅觉传播与口腔萦绕；雷改变刺激的跃动和爆裂方式。
- **冻结冰块 vs 冰元素平抑**：冻结产物直接以冰块实体口感参与品尝；未反应的冰元素则通过平抑已存在的风味来表现，不把两者算作同一种效果。

所有风味名称只用于描述，不强迫生成新的独立游戏物品种类，也不自动代表固定数值倍率。
