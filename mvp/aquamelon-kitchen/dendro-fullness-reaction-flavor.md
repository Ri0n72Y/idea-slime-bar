# 水瓜厨房：草元素「丰盈感」与激化／草原核风味

> **状态：感官设计共识（2026-10-13），不等于数值／运行时实施合同。**
>
> 本文记录已确认的草元素风味和两条反应路线。参考 [水火冰风味 PR #24](https://github.com/Ri0n72Y/idea-slime-bar/pull/24)、[岩结晶 PR #25](https://github.com/Ri0n72Y/idea-slime-bar/pull/25)、[雷活跃度 PR #26](https://github.com/Ri0n72Y/idea-slime-bar/pull/26)。物质量与触发规则由 [反应结算设计 PR #21](https://github.com/Ri0n72Y/idea-slime-bar/pull/21) 另行维护。

## 1. 草元素的两层身份

**世界观底层：生发。** 草对应生命的生长、维持和发展，也关联智慧权能；水与其相近却不同，水更接近原始胎海的创生，草强调生命诞生后的继续生长与维持。这是本项目用于风味转译的世界观理解，不声称是原作严格逐字定义。

**直接感官：丰盈感（Fullness）。** 已确认将「丰盈感」作为草的基础风味方向：原有风味在品尝中逐渐变得充实、丰富、舒展，像鲜嫩植物果肉的饱满体验或优质菌菇汤逐渐展开的鲜香。并非自动增加甜、鲜、香浓度，也不等于岩的黏稠或冰的持久度。

普通水瓜本味如极淡椰子水，带有轻微植物甘味，天然亲近水、草。草增强可以让这种原本很淡的生命性状略显饱满；没有丰富食材时，变化也允许微弱。具体甜味来自甜甜花，酸味来自泡泡桔等真实食材；蘑菇鲜味也来自菌菇，不是纯草直接制造的第五味。

**设计分层**：草＝丰盈感；「生发」解释其作用机制，而不是另一条已批准的运行时维度。两条反应路线如下：
- **激化**：已有生命材料的鲜香潜力苏醒、活跃、延续；发展原有风味。
- **水草绽放**：水的创生与草的生命共同生成新生植物性草原核组织；在咀嚼中释放风味。

## 2. 激化路线：鲜香潜力苏醒

参考须弥蕈类的原作料理「杂菇荟萃」「巡林官精选」：优质菌菇经过恰当料理，可以让不同菌类本有的鲜香和质地充分表现，而失败料理可能突出不悦的土腥味。**这是食物感官类比，不是草元素等于蘑菇鲜味的证据。**

| 反应 | 已确认的核心意向 | 入口／中段／回味的典型描述 |
| --- | --- | --- |
| **原激化** | **鲜香潜力苏醒**，生命刚开始活跃 | 入口仍轻淡；中段已有植物风味开始显露，像菌菇潜藏的鲜香逐渐苏醒 |
| **超激化（雷继续作用）** | **更加活跃**，鲜香鲜明、迅速丰满 | 风味较快展开，伴随雷的活跃、细微跃动，呈生命活力般的鲜明丰盈 |
| **蔓激化（草继续作用）** | **更加回味悠长**，丰盈持续发展 | 入口相对柔和，品尝中逐渐丰满，吞咽后仍留有绵长、充实的余韵 |

关键对照：**苏醒 → 活跃／绵长**。超激化不是把鲜味统一乘以更大的值；蔓激化也不必比超激化更浓，只是更强调中后段的持续展开。由于材料不同，激化未必保证更美味；不悦气息也可能被突出。

普通超导（冰雷）先前已定义为让**品尝者更易辨认**现有风味；草雷激化则使**材料自身的潜在风味得到进一步发展**。两种机制在语义上不能合并。

## 3. 绽放路线：新生的可食草原核

**水＋草＝创生＋生命。** 绽放让水瓜内部生成一粒一粒独立的植物性组织；**不是把整颗水瓜或整杯果汁直接变成水晶胶冻**。草原核采用「颗粒果」意向：外形像**没有硬籽的石榴**，由许多饱满的独立果粒构成；吃起来更接近成熟**葡萄**，柔嫩、多汁，咀嚼时释放清润与丰盈感。

这是水瓜厨房对草原核的可食性状设计；原神战斗中的草原核不是普通植物种子，本项目也不因「种子状」一词让它自然具有可播种的植物身份。

| 反应 | 已确认的组织形态与口感 | 风味释放 |
| --- | --- | --- |
| **水草绽放／草原核水瓜** | 果实内部密布一粒粒柔软饱满的植物性果粒；**无硬籽石榴的颗粒排列，葡萄般的柔嫩多汁** | 轻轻咀嚼后**温和释放**原本清润而充实的风味 |
| **草原核＋雷 · 超绽放** | **活跃的绿色弹性果粒**，更有嚼劲、更富回弹 | **边嚼边释放风味**，活跃而持续；不等同于雷岩的跳跳糖爆裂 |
| **草原核＋火 · 烈绽放** | **入口即破的爆爆珠**，果粒内部原有风味集中 | **尽可能将原本跨阶段的味道前移至前奏**，一咬便猛烈迸发、瞬间充满口腔，随后较快回落 |

**三个原核之间的核心差别是风味释放的时间结构**，不强制改变味道总量：

| 品尝阶段 | 普通草原核 | 超绽放 | 烈绽放 |
| --- | --- | --- | --- |
| **入口** | 柔嫩、饱满、清润 | 有嚼劲，活跃感开始表现 | **味道瞬间爆发**，集中充满口腔 |
| **中段** | 颗粒随咀嚼温和放汁 | **弹性咀嚼中持续释放** | 峰值之后迅速回落 |
| **回味** | 温和的植物丰盈感 | 活跃消退，仍有风味延续 | 主要风味已在前段释放，余韵相对较轻 |

超绽放的活跃并不要求果粒真实产生气泡。烈绽放可伴随火的非物理温度**热灼**，但它最突出的反应身份是**爆爆珠和入口风味前置**，不自动附加辣椒味、焦香或高甜度。

## 4. 与岩结晶及雷感官的区分

| 比较 | 草原核（绽放系） | 岩结晶 |
| --- | --- | --- |
| 形成原则 | 水草共同生成**新生植物组织** | 岩使既有内容物**有序凝聚、定形** |
| 共同外观 | 独立的柔软、饱满、可咀嚼果粒 | 晶质排列的可食**水晶胶冻** |
| 反应特色 | 普通柔嫩、超绽放弹性释放、烈绽放入口爆珠 | 水岩滑润、火岩弹热、冰岩脆、雷岩噼啪 |
| 雷相关区别 | **超绽放**侧重绿色弹性颗粒，越嚼越释放风味 | **雷岩**侧重跳跳糖般噼啪爆裂触觉，**无需真实气泡** |

岩的「凝聚」和草的「丰盈」可能都改变最终食用口感，但前者属于结构形成，后者属于生命内容物和风味发展；暂不设计两类特殊产物之间的混合反应。

## 5. 统一元素感官方向与尚未确认事项

| 元素 | 已确认感官方向 |

| 水 | 清润 |
| 火 | 热灼 |
| 冰 | 平抑 |
| 岩 | 凝聚 |
| 雷 | 活跃度 |
| **草** | **丰盈感** |
| 风 | **尚未确认** |

七维感官表征仍只是设计方向；以上名称**不是**既有 `FruitElementAmount[7]`／`FlavorRatio[7]` 的替代字段，也不直接决定五味值或统一三阶段数据结构。

**明确不在本轮**：草原核的物质量、30G／1U等触发规则、后续投入的消耗或守恒、激化产物账户、强度曲线、风味发展算法、释放时间公式、料理加工路线、材料字段、Web／千星奇域代码、CI。以 [反应结算 PR #21](https://github.com/Ri0n72Y/idea-slime-bar/pull/21) 等独立专题为准；本轮仅固定**风味意向**。
