# 水瓜厨房：现行七元素与反应风味

本文件维护当前品尝语义。**旧三阶段五味与口腔感觉共27项量化 Taste 已过期**，不再作为游戏数值输出或待补公式；入口/中段/回味仍可作为AI自然语言叙述顺序。物质量与味觉不是同一个向量：以果汁的**现存**`E_free[7] + Products[]`作为确定性事实。

## 七元素感官基准

普通水瓜汁近似极淡椰子水，柔和、清润、略有植物甘味；七元素不直接制造固定甜酸苦咸鲜。

| 元素 | 核心感官方向 | 不应偷换为 |
| --- | --- | --- |
| 火 Fire | 热灼，温水至烈酒般灼感 | 真实高温、辣椒、焦香 |
| 水 Hydro | 清润、通透、柔和、水瓜本味润泽 | 显著甜味、鲜味 |
| 风 Anemo | 已有香气的传播；纯风是口腔柔和扩散、环绕、消散的萦绕感 | 自带固定花香或酒精味 |
| 雷 Electro | 活跃度、跃动、振动或爆裂刺激 | 固定酸味、必须有真实气泡 |
| 草 Dendro | 生发与丰盈，已有风味逐渐充实、发展 | 无来源地产生甜、鲜 |
| 冰 Cryo | 平抑现有风味峰值、起伏及释放 | 冰块、冰镇或薄荷凉 |
| 岩 Geo | 凝聚、形成有序胶质/晶质组织与咀嚼结构 | 咸味、矿物味 |

## 已确定的反应风味

| 反应产物/方向 | 实际感官解释 |
| --- | --- |
| 水→火 正蒸发 | 清冽、柔润，类似极淡蜂蜜水但不真正加糖 |
| 火→水 逆蒸发 | 温灼，先有热感，退去后显出水瓜微甘 |
| 火→冰 正融化 | 炽灼，更强的火系热灼，不自动带焦香、辣椒味 |
| 冰→火 逆融化 | 凝味，平抑原有味道的变化与释放 |
| 水雷 感电 | 细密、连续跳动的麻感，气泡水意象但不必产生气泡 |
| 火雷 超载 | 瞬间爆裂式强烈热刺激，不是持续燃烧热 |
| 冰雷 超导 | 绵密均匀的酥麻；已有风味更容易辨认，并非增加糖或酸 |
| 水冰 冻结 | **直接作为冰块处理**，有冰冷与冰质触觉，区别于冰元素的平抑 |
| 火草 燃烧 | **草的生发被火激发的活跃、持续热感**，不是超载的爆炸热，也不默认焦糊烟熏 |
| 岩水 结晶 | 清润、滑润柔弹的水晶胶冻 |
| 岩火 结晶 | 热灼与弹性回弹兼有的弹热晶冻 |
| 岩冰 结晶 | 脆裂利落、具有平抑特征的清脆晶冻 |
| 岩雷 结晶 | 晶质咀嚼中跳跳糖般跃动噼啪，不要求真实气泡 |
| 雷草 原激化 | 已有鲜香潜力苏醒、开始显露 |
| 激元素＋雷 超激化 | 更快速、活跃地发展已有风味 |
| 激元素＋草 蔓激化 | 丰盈向中后段展开、回味绵长 |
| 水草 绽放 | 无硬籽石榴状植物果粒、葡萄般柔嫩多汁，温和释放风味 |
| 草原核＋雷 超绽放 | 弹性绿色果粒、越嚼越持续释放 |
| 草原核＋火 烈绽放 | 一咬即破的爆爆珠，风味集中到入口 |
| 风扩散 | 增强**已有**香气的传播，不能凭空创造新香型，且不生成独立Swirl产物 |

数值消耗、触发资格和SRP优先级以[反应结算 §6.18](fruit-reaction-settlement-design.md)为准；以上是已确认的风味语义而非额外数值倍率。

## 第一反应外观与多重反应风味

**第一次真实生成的反应产物**及方向锁定整颗果子的名称和图标；后续再发生反应，外观仍保留首次产物身份，即使首次产物后来被进阶消耗，也不重选。**实际味道**读取全部当前自由元素与当前存在的所有反应产物；后发生的反应同样参与品尝，已经被消耗掉的历史产物不重复计味。单纯风扩散没有产物，不触发整果图标锁定。
