# 千星 2D Lua：最小实施约定

本页只保留**已验证经验与明确边界**，一行一条；不附代码、调研链接或 API 探索过程。

## 已由本项目编辑器验证

- 已验证：本地 Lua 能挂到创作者手工布置的客户端 UI 容器上。
- 已验证：脚本宿主可由 `script.object` 获取，返回的宿主类型为 `ClientUIContainerControl`。
- 已验证：可通过宿主查找已有文字控件、更新 `.text` 并看到实时内容改变。
- 已验证：最小 PC 鼠标点击可响应已有控件的点击监听。

## 已形成的工程约定

- 采用**唯一 Game 世界状态**；UI 为只读投影加动作入口；感官展示只读取真实对象及其物质事实。
- Lua 模块按功能边界拆分：入口/UI、状态、向量、曲线、土壤、生长、时间结算与只读展示。
- 目前仅有基础 Lua UI 连接和 Seed→Sapling 计算切片的证据；完整器官、反应和果汁闭环仍需验收。
- 每个需要打包的 Lua 模块都应建立对应的客户端脚本资源映射；多模块加载仍须在新仓库/关卡实机验收。
- 界面位置、锚点、尺寸与字体由创作者在编辑器静态维护，Lua 不自动更改。
- 文本、图片、按钮、弹层统一按编辑器对象名称绑定；名称键与稳定业务对象 ID 不能混用。
- 已有元素 PNG 的文件路径不等于编辑器可直接使用的图片 `imageId`；运行时切图须使用已配置的图片资源 ID。
- 控件显隐应针对子面板，不能随意禁用挂载主 Lua 脚本的宿主根容器。
- `OnUpdate` 等技术更新频率不是一个 uh；唯一模型时间按 **10秒/uh** 换算并避免重复结算。
- Debug 和自然推进调用同一领域逻辑，不保留第二套计算模型或重复存储的物质账户。
- Lua 只承诺已真实观察到的控件能力；图片替换、禁用、长文本滚动、手机触屏、复制等尚不能称为本项目实机验证通过。
- 长提示词优先采用独立文字阅读层；外部剪贴板复制能力**尚未证实**，必须支持可完整查看的交付退路。
- 仅使用本地 Lua 计算与 UI；不加入服务端节点图、多人同步或通用 ECS 框架。
