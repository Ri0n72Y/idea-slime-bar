# 水瓜厨房 — 当前2D Lua参赛实施路线

> 当前参赛实施范围见 [Issue #34](https://github.com/Ri0n72Y/idea-slime-bar/issues/34)。此页替换原先将GIA节点图、完整料理、汁液混合和未来多人作为依赖的旧路线图；**不更改原有玩法文档和未来正式版研究**。

**技术边界**：全部计算与动态UI由本地Lua负责；唯一world，Game负责计算/结算，UI仅读取与请求动作，Taste仅读汁快照生成全文；静态编辑器控件和图片由创作者布置/导入。不引入节点图、ECS、网络、多人物品框架、离线持久化或未来兼容层。

## P0 分阶段验收

1. **Lua接线门槛**：以已有`script.object/FindChild`及最小文字点击实机反馈为基础，独立验证模块`require`资源映射、唯一10s/uh计时、图片`imageSource/imageId`与RGB更新、长文TextWindow实际可交付方式；**API文档可见不等于已实机通过**。
2. **植物起步**：[生长系统](growth-system.md)固定50V纯球、0.25uh半衰、Soil1000V、Seed45不断代/Seedling90逐维结转Reserve、首Bud同步产生；两种真实元素输入轨迹有不同亲和。
3. **完整器官**：Sapling Reserve180、M95/W12、B0=5.4、阶段根系2/1.85/16、叶30%与母叶花果80%、Bud20/Leaf26/连续生殖12→40→90G；每24uh后续Bud机会去重。
4. **成熟反应**：[§6.18](fruit-reaction-settlement-design.md)全部已确认的实际消耗、产物、风扩散优先、感电R1首次12G足额、非风R2同合法事件即时结算；90～150G线性自然富集，不裁剪合法反应物质。
5. **外观与风味**：[培养显色](elemental-cultivation.md)由Lua七元素RGB归一混合、成长叠色30%、首次产物锁图标/名称、后续产物仍参与[实际风味](taste-model.md)；冻结是冰块，燃烧是草生发受火激发的活跃持续热感。
6. **收获与交付**：一颗熟果→唯一一份汁，`E_free+Products`账户一次转移；输出全七元素、全部当前产物、首反应身份和风味、事实与演绎分离的完整中文AI提示词，真实可向外部AI交付。
7. **整体验收**：两条真实元素培养路径从放土到品尝提示词；Growth账户边界无复制/丢失、冻结/燃烧与多重反应区分、UI不可执行按钮没有伪成功、普通界面不泄露内部向量。
