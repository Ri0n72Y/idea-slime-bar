# 水瓜厨房：风元素「嗅觉扩散与萦绕感」设计

> **状态：感官设计共识（2026-10-14）；非数值／运行时实施合同。**
>
> 本文仅固定风元素及扩散反应的风味意向。六元素共识见 [水火冰 PR #24](https://github.com/Ri0n72Y/idea-slime-bar/pull/24)、[岩 PR #25](https://github.com/Ri0n72Y/idea-slime-bar/pull/25)、[雷 PR #26](https://github.com/Ri0n72Y/idea-slime-bar/pull/26)、[草 PR #27](https://github.com/Ri0n72Y/idea-slime-bar/pull/27)。元素消耗和触发条件独立见 [反应结算 PR #21](https://github.com/Ri0n72Y/idea-slime-bar/pull/21)。

## 1. 风元素的感官身份

- **世界观／作用意向：扩散、流动、传递。** 风使已有感官内容向外传播，而非凭空生成具体味道。
- **核心感官领域：嗅觉。** 风发挥食材与元素原本已有的香气，使其释放、传播并被闻到；花香、果香、酒香、烘烤香等必须来自相应材料或既有风味，不是纯风统一赠送的香型。
- **纯风的直接口腔体验：萦绕感。** 感受由舌尖开始，向口腔舒展，柔和环绕，再逐渐自然消散。这是描述性的感官意向；不先规定为具体触觉刺激或生理机制。

嗅觉与口腔中的风味体验可以相互联系，但不等同。尤其不可将风简化为「闻起来更浓」的单一倍率，亦不可将萦绕等同于气泡、薄荷凉、辛辣或黏滞。

## 2. 纯风水瓜：蒙德酒的温和意象

普通水瓜的基底仍是近似极淡椰子水的清淡植物甘味。纯化风元素形成的**风水瓜**，参照蒙德酒与至冬火水的感官对比：前者是温和、有风味的舒展体验，后者常被类比为高烈度烈酒；这只是设计意象，不要求模拟真实酒精或给原作酒种建立统一的酒精度规则。

| 品尝阶段 | 风水瓜的表现 |
| --- | --- |
| 入口 | 清淡、轻柔，不以猛烈刺激开场；可感到原有水瓜的微弱植物香 |
| 中段 | 若有若无的感受从舌尖展开，轻柔地环绕口腔；原有香气随着这一过程舒展 |
| 回味 | 感受短暂萦绕，随后自然消散，留下淡雅余韵，而非久久凝滞 |

风水瓜**不是酒精口味**，不自动具有酒精灼烧、醉酒、气泡、薄荷清凉或刺激性辛辣。风需要在没有额外香料的纯化果实中仍然可被体验到；其独立口感是「流动的萦绕」，但不预先发明触觉数值或释放时间公式。

**边界**：风的萦绕是动态地扩展与散去；草的丰盈是既有风味的充实、发展；冰的平抑是抑制与调和。三者不是同一个「持续时间」属性。雷的活跃也不同于风的柔和流动。

## 3. 扩散反应：增强对应元素的嗅觉表现

风与水／火／冰／雷的扩散，从共同原则出发：**发挥参与扩散的元素及材料本来具有的气味，让香气更容易释放、传播和被察觉。** 用户确认扩散具有嗅觉上的加强作用，但具体增强倍率、距离、释放曲线尚未确认。

以下为已确认原则之下的**描述候选**，并非逐项批准的特殊反应产物或规则：

| 扩散方向 | 可能的嗅觉表现 | 不应自动附加 |
| --- | --- | --- |
| 风＋水 | 原有清淡植物香更清新、舒展地散发 | 甜味增加、固定水生花香 |
| 风＋火 | 既有香气在前段更鲜明地散发，与热灼口感并存 | 焦香、烟熏、酒精气味 |
| 风＋冰 | 已有香气柔和、均匀地展开，仍保留冰的平抑特征 | 薄荷味、真实降温 |
| 风＋雷 | 原有香气呈更活跃的释放表现，与雷的跃动感并存 | 臭氧味、气泡或额外化学气味 |

扩散既可能使香气更突出，也可能改变其**释放速度、出现阶段、传播方式**。不能仅因为扩散了不同元素就自动创造一组固定香型。扩散在数值系统中的元素库存、优先级、触发方向及守恒仍由 PR #21 单独决定；这里不更改。

## 4. 蒙德文化与植物的设计参考

- **风车菊**：借花朵随风转动，让不可见的风获得可见表现；它启发的是「风使潜在性质显现」，并不证明风车菊自身具有指定香型。
- **蒲公英**：随风传播，与蒙德的自由、远方及酿酒文化相关；其文化意向可用于解释香气与记忆的流转，不能推导风自动生成酒精味。
- **风息花、荆夫港**：芳香花卉、香水与当地料理提供嗅觉和食物的联结参考；植物的香味属于植物本身，不能直接上升为风元素的固定花香。
- **蒙德酒与至冬火水的比较**：为纯风水瓜的温和、环绕和消散提供体验类比，**不是**真实酒精、风味配方或生理效果的设定。

上述参考属于世界观／食物意象的设计转译；不要将所有文化关联误写为原作直接规定的元素机制。

## 5. 七元素感官表征与边界

| 元素 | 已确认感官方向 |
| --- | --- |
| 水 | 清润 |
| 火 | 热灼 |
| 冰 | 平抑 |
| 岩 | 凝聚 |
| 雷 | 活跃度 |
| 草 | 丰盈感 |
| **风** | **嗅觉扩散；纯风口感为萦绕感** |

此表是**设计语义**，不是新的运行时字段，也不能将现行 `E_free[7]+Products[]` 物质量直接当成口味分数；旧27项Taste数值映射不用于当前风味合同。
