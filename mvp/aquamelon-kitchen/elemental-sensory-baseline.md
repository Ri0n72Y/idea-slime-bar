# 水瓜厨房：水、火、冰元素的风味性状与四种增幅水瓜

> **状态：风味描述层的设计共识，2026-10-10。** 此文记录已讨论并选择的感官方向与果实原型，不批准新的数值公式、物质量结算、数据字段、反应解锁或 runtime 实现。
>
> 本文属于 Aquamelon Kitchen 的**风味策划**。元素论中的实际附着、触发、消耗、产物和残留量另由数值设计负责；千星奇域与 Web 只共享经确认的设计语义，不直接共享运行时代码。

## 1. 水瓜是一种饮料基底，而不是元素调味剂

- 水瓜天生偏向**水与草**元素；其基础风味更接近水的性质。
- 普通水瓜汁近似**甜味极淡的椰子水**：几乎像水，清爽、柔和、带极轻的植物甘味，却比普通饮用水更有满足感。它独立于元素反应，已经是值得饮用的基底。
- 在 Slime Bar 的设定中，顾客普遍偏爱水瓜水调制的饮品，而非直接兑水；本项目延续这种**基底的独特饮用价值**，不把它简单换算为甜度或浓稠度。
- 甜甜花、薄荷、泡泡桔、花瓣等**具体食材**可以带来显著的甜、清凉、果香或花香。它们不自动归属于水、火、冰任何单一元素；风味成分、元素性状、料理加工需区分来源。
- 不以“火＝辣／水＝甜／冰＝冰镇”预设七元素基础 Taste。此前按七元素配给固定九维味觉的探索不作为本次风味基准。

## 2. 三种元素：感官性质，而非直接的五味配方

| 元素 | 核心感官性质 | 轻度到极端的变化 | 明确不等同于 |
| --- | --- | --- | --- |
| **水 Hydro：清润** | 清冽、通透、润泽、柔和，贴近水瓜自身本味 | 水瓜已有的清润和饮用满足感变得鲜明；仍可能没有明确的浓甜、浓酸 | 甜味、薄荷清凉、海产鲜味 |
| **火 Pyro：热灼** | 实际温度不必升高的温热／灼烧口感 | 从温水般的暖热感，发展为如烈酒般烧灼，却不必有酒精、辣椒或焦香味 | 食物真实高温、辣椒辛辣、草木燃烧的烟熏与焙香 |
| **冰 Cryo：平抑** | 对已有味觉与口腔感觉的峰值、起伏、持续和释放作约束 | 适量时更平稳持久；过量时失去层次；极端时味道存在却难以在舌尖化开 | 冰镇温度、单纯“凉度”、无条件提高协调／美味 |

**水与冰都可能被形容为“清冽”，但不是同一回事**：水让原本清淡的水瓜本味更清润、舒展；冰令原有风味平稳、收束，并可能压住水的清冽感或火的热灼感。

火的强烈表现借鉴**烬芯花“甜到灼烧”**的意象：强烈的刺激不必是“辣再叠加甜”。烬芯花具体的甜来自植物花蜜，不能据此将纯火元素定义成甜味。

### 2.1 冰的平抑值：描述锚点

| 候选强度 | 对饮用体验的描述 |
| ---: | --- |
| **0** | 不平抑，原有风味自然起伏 |
| **1** | 略微柔化明显的峰值与转折 |
| **3** | 起伏适度降低，风味表现更持久，衔接与融合比较良好，但各自特点仍可分辨 |
| **5** | 入口、中段、回味的变化趋同；不同风味也难以分辨，缺乏层次与过渡 |
| **超过 5（极端）** | 进一步阻碍风味被感知：味道本身仍存在，仿佛凝结封存，无法在舌尖化开 |

这里的 0／1／3／5／超过5 是**感官标尺与描述锚点**，不是元素量直接换算公式，也不要求增加超过5的新持久化数值范围。平抑可同时影响甜酸等食材本味、火的热灼、水的清冽及其他元素体验；不应只压制基础五味。

**设计取舍**：适量平抑能帮助尖锐、复杂的饮品融合，却不保证更好喝。普通水瓜本身就很清淡，冰融化果若只有平抑而缺少其他配料，可能更寡淡，不必刻意把它包装为优质直接饮品。强度5与极端封存也不是同一种效果。

## 3. 四种增幅水瓜：同样的反应类型，不同触发元素

蒸发与融化放大**触发元素的主要感官性质**。参与反应并被消耗的底元素决定反应条件／类型，可影响结果的风味印记，但不能将其原始味道再作为完整一份主味重复叠加。未参与的元素形成较弱残味；量、持续结算与消耗的规则不在本文设定。

| 果实候选名 | 触发方向 | 原作增幅倍率参考 | 主风味及描述 | 典型用途 |
| --- | --- | --- | --- | --- |
| **清冽水瓜** | 水打火，水蒸发 | 水 ×2 | 本来就近似水的水瓜更清冽、润泽；火参与使它温润、柔和，像极淡的蜂蜜水，但并不显著增甜 | 可以直接饮用，适合清淡／花香饮品 |
| **温灼水瓜** | 火打水，火蒸发 | 火 ×1.5 | 水瓜仍然清淡，却有温水、热水般的口腔热感；极端时像无酒精的烈酒，灼感退去后浮现水瓜微甘 | 强度较高时偏小众，适合有热灼特色的调饮 |
| **炽灼水瓜** | 火打冰，火融化 | 火 ×2 | 与火蒸发**同源的热灼**，在相同参与火量下有更高增幅潜力；不必出现姜辣、焙香、冰镇感 | 更强烈的火系调饮基底，未必适合直接喝 |
| **凝味水瓜** | 冰打火，冰融化 | 冰 ×1.5 | 风味被平抑而趋于持久、安静；过强时失去层次，极端时微甘也难以被感知 | 主要用于调和复杂饮品；纯喝可能寡淡 |

以上名称是风味识别用的**暂定名称**，不是运行时商品类型或必然触发结果。倍率只说明反应方向的原作参考，**不等于已确定的水瓜风味计算公式**。同一元素参与量下可比较增幅，但高元素量的火蒸发果也可能比低元素量的火融化果更热灼，不按反应名称固定成品强度。

### 3.1 清冽水瓜：水蒸发

水瓜原本轻淡的清润被突出，入口清澈而鲜明，却没有尖锐刺激。火元素在反应中参与并被占用，使清冽呈现出温润、不生硬的感觉。它像一杯**甜到几乎无法察觉的蜂蜜水**：重点并非糖度，而是喝过之后充实、润泽的满足感。

加入**甜甜花**后，饮品才真正获得明确的甜味；再配合花瓣香气，可以发展为温润的花蜜饮。这里甜与花香来自具体食材。

### 3.2 温灼水瓜：火蒸发

即使果汁实际温度不高，也仿佛在饮用偏热的水。火的表现较轻时只是暖热；随着参与反应的火风味增强，可以接近**没有酒精味、却有烈酒般入口烧灼感**的体验。灼烧退去后，才更容易察觉水瓜本来的微甜与柔和，形成可描述为“灼后回甘”的转折。

不是自然带有辣椒辛香、焦苦、烟熏或乙醇；高热灼不必人人喜欢，也不代表劣质。

### 3.3 炽灼水瓜：火融化

与温灼水瓜使用**同一种火元素热灼方向**，不另造一套“融化专属火味”。火触发融化的增幅倍率更高，使相同参与量下更容易形成强烈的热灼。作为底元素参与的冰，不自动给它附加冷感或额外平抑；是否存在独立的融化反应印记尚待研究。

### 3.4 凝味水瓜：冰融化

它不是一杯格外冰凉的果汁，而是原本轻柔的风味变得平静、持续。适量平抑可以使复杂饮料的强烈刺激和阶段起伏更协调；但**只用清淡的水瓜汁直接饮用时，平抑可能使它更寡淡**。继续增强后，入口、中段、回味难以区分；极端时甚至水瓜本来极淡的植物甘味都无法充分化开。

它的独特价值允许出现在**调饮**，而不是被设计成一种天然更好喝的水瓜。

## 4. 后续方向：可能从九维 Taste 走向七维元素风味

目前只是一个**架构候选**：最终可以尝试以七元素各自的感官贡献形成**七维元素风味表征**。已能描述其中三种候选轴：水＝清润、火＝热灼、冰＝平抑；**风、雷、草、岩四个维度尚未确定**，不得自动补全成酸、苦、咸、麻等固定标签。

需要始终区分：

1. **FruitElementAmount[7]／FlavorRatio[7]**：权威的元素累计事实与其组成比例，不是感官七维向量；
2. **候选七维元素风味**：元素反应后如何影响饮用体验的**派生感官表征**，维度与映射都未定；
3. **具体食材的基础味觉、香气、质地**：例如甜甜花、泡泡桔与薄荷的贡献；
4. **最终饮料的入口／中段／回味**：品评用的感官展开，未来再确定转换、评价与数值边界。

之前的“五味＋四项口腔感觉”可作为历史的**最终饮料描述方案**继续评估，但不再要求给每个原始元素机械分配一整套九维基础味觉。**尚未决定**是否废弃、调整或保留三阶段下的五味评分；七维方向不自动替换已经确认的运行时数据结构。
