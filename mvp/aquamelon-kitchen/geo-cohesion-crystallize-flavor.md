# 水瓜厨房：岩元素凝聚与四种结晶水晶胶冻

> **状态：2026-10-10 风味／口感设计共识。** 本文记录已确认的**感官方向和结晶果原型**，不授权数值、附着消耗、反应产物数量、运行时材料类型或处理链实现。
>
> 同属 Aquamelon Kitchen 风味研究，参照 [水、火、冰感官基准 PR #24](https://github.com/Ri0n72Y/idea-slime-bar/pull/24)；与 [元素结算设计 PR #21](https://github.com/Ri0n72Y/idea-slime-bar/pull/21) 独立。该文件本身不改变权威的 FruitElementAmount／Growth 数据合同。

## 1. 岩的感官贡献：凝聚（Cohesion）

**岩元素不是“咸味”“矿物味”，而是让原本流动的水瓜汁逐渐形成有序、排列规律的结构。**

- 液体中的内容物从自由流动，逐渐凝聚为更稳定、有规则的组织；能够形成有节奏的内部分隔、包裹及破裂方式。
- **“黏稠”是早期可感知表现，不是岩元素性质的完整定义。** 黏稠的液体不等于晶体；坚实的胶冻也不一定黏牙。
- 强度进一步增加可出现胶质、弹性、晶质组织与特定断裂方式；过量可能过韧、过硬、难以食用或妨碍内部风味释放。
- 岩本身不必增添新的五味；水瓜本味与其他食材风味仍然存在，凝聚主要改变它们的物理承载、空间分布和食用口感。
- **凝聚不同于冰的平抑**：岩首先作用于物质组织和空间结构，冰主要作用于风味强度、时间起伏及可感知释放；二者的极端表现都可能使内部风味不易尝到，但机制不同。

### 候选感官分级（非数值结算公式）

| 凝聚描述锚点 | 物理／口腔体验 |
| ---: | --- |
| **0** | 普通可流动水瓜汁 |
| **1** | 略增稠度，口感更有承载感 |
| **3** | 柔软凝胶组织开始明显，有独立咀嚼反馈 |
| **5** | 高度有序的可食水晶胶冻，弹性、脆裂等结构特色清晰 |
| **超过 5（极端）** | 可能过度坚实、黏韧或难以咬开，内部风味不易释放 |

0／1／3／5 是描述基准，不承诺某单位岩元素与档位线性对应；“排列规律”是游戏中幻想植物组织的表现，不宣称真实果冻必须具有物理晶格。

## 2. 结晶反应的共通产物：水晶胶冻

**结晶型水瓜将原本以汁液为主的内容物转化为可食的水晶胶冻**，而不只是给普通果汁增加一点黏度。反应保留参与元素所代表的主风味方向，通过不同的晶冻结构改变承载与咀嚼释放。

| 结晶组合 | 已选择的主要表现 | 现实食感类比 | 不应额外假定 |
| --- | --- | --- | --- |
| **水＋岩** | **滑润晶冻**；保有水的清润，光滑、柔弹而润泽 | 椰果、荔枝的滑嫩感 | 水本身贡献强甜；晶冻自动带荔枝香 |
| **火＋岩** | **弹热晶冻**；保有火的热灼错觉，咬感有明显弹性与回弹 | 温感、弹牙的蒟蒻／胶冻 | 必须物理加热，或天然带生姜辣、焦香 |
| **冰＋岩** | **清脆晶冻**；脆裂干净、利落，保留冰的平抑性状 | 脆壳、易断裂的晶质胶冻 | **冰镇、低温或薄荷味** |
| **雷＋岩** | **跃动晶冻**；咀嚼时产生跳跳糖般的噼啪、爆裂触觉，**无需真实气泡** | 跳跳糖的爆裂口感（不是实际冒泡） | 雷一定产生真实气体，或自动带酸味、麻木感 |

四种反应结果为**候选食用形态与质地描述**，不预设正式产物命名、数值、固定材料拆分、自动饮品加工或顾客喜好结论。**雷的核心感官性质已确认为活跃度**：爆裂的触感由雷元素提供，不要求真实气泡，也不等于“雷＝酸麻”。详见 [雷元素活跃度与反应风味 PR #26](https://github.com/Ri0n72Y/idea-slime-bar/pull/26)。

## 3. 结构与口味的关系

- **基础水瓜**本味如极淡椰子水；凝聚并不要求它忽然产生浓甜。
- **结晶**是有独立组织性状的反应产物；不能把“岩富集使果汁轻微增稠”和“结晶已生成水晶胶冻”视为同一触发事件。
- 与**冰**的“平抑”相区别：岩可能使味道仍在胶冻中，咬破后释放；冰极端时可能使味道存在但感官难以感知。
- 同样叫水晶胶冻，不必都很坚硬：水岩滑嫩、火岩弹韧、冰岩脆、雷岩跃动，**统一的凝聚规则与元素特性共同决定差异**。
- 质地特色不代表优劣：太黏、太韧、太硬或噼啪过强均可能降低适口性，但本轮不制定“失败强度阈值”。

## 4. 与七维设想及结算研究的边界

目前确认的七元素感官方向已有五种：**水＝清润、火＝热灼、冰＝平抑、岩＝凝聚、雷＝活跃度**。风、草尚未确认。

候选的“七维感官表征”**不是**既有 `FruitElementAmount[7]` 或 `FlavorRatio[7]`，也不强迫每种元素承担五味之一。具体食材贡献的甜酸苦咸鲜、最终饮料入口／中段／回味，以及凝聚与反应产物质量之间的转换关系留待单独研究。

特别是结晶触发方向、岩与目标元素的消耗比例、稳定产物总量、原有材质如何转换为水晶胶冻，**全部由元素结算／后续实现专题决定**；本文不替其创建物质量公式或运行时字段。
