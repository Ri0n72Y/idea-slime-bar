# Aquamelon Kitchen｜七元素感官评级与三阶段口感映射

## 1. 「尝一尝」与三阶段

玩家点击任意对象，均可打开「尝一尝」。页面直接显示该对象已定义的感官基调、**入口／中段／回味各自的评级**以及全部阶段标签和整体标签；没有感官定义时显示「未定义」，不杜撰评分。

- **入口 Entry**：最初接触时的先发特征与峰值。
- **中段 Body**：含饮、咀嚼时的展开、持续及组织释放。
- **回味 Finish**：结束品尝后的延续、衰减与消散。

三阶段使用相同的七个感官基调：**火·热灼、水·清润、风·扩散与萦绕、雷·活跃度、草·丰盈感、冰·平抑、岩·凝聚**。这些是感官体验的轴，不是元素库存字段。

## 2. 1／3／5 强度评级

| 数值 | 级别 | 含义 |
| ---: | --- | --- |
| **1** | **轻微** | 确实可察觉，但只是局部、柔和或短暂表现 |
| **3** | **明显** | 稳定且容易辨识，成为这一阶段的主要特征之一 |
| **5** | **强烈** | 在这一阶段显著主导体验，甚至改变其他基调的呈现 |
| **0** | **不存在** | 已明确确认该基调没有可感知表现 |
| **未定义** | **未知** | 缺少合法评级依据，不能假装为0 |

本评级衡量**感官强度而非好喝度、品质或喜好**。同一阶段可有多条非零基调，互不求和、不强制归一；1／3／5是首版三级描述锚点，2、4及小数不必自动生成。超过5的体验可采用描述性标签，不擅自扩展评分域。

### 七种基调的具体锚点

| 基调 | 1 · 轻微 | 3 · 明显 | 5 · 强烈 |
| --- | --- | --- | --- |
| 火 · 热灼 | 轻柔温热错觉 | 入口灼感清楚可辨 | 烈酒般的强烈烧灼冲击，但不要求真实高温 |
| 水 · 清润 | 略显通透柔和 | 清冽润泽清楚可辨 | 清润主导体验，但不会自动产生新香型 |
| 风 · 扩散／萦绕 | 已有香气略微舒展 | 嗅觉传播和口腔萦绕明显 | 传播与空间环绕成为主要特征 |
| 雷 · 活跃度 | 微弱、短暂的活动或振感 | 反复脉冲或细密微振清楚可辨 | 爆发或密集活动显著突出；形式依反应变化 |
| 草 · 丰盈感 | 既有风味稍显饱满 | 既有风味逐步充实、展开 | 丰盈发展成为阶段主体 |
| 冰 · 平抑 | 略微柔化峰值和转折 | 起伏适度减少，衔接顺畅，各基调仍可区分 | 三阶段趋同、层次与释放明显受到抑制 |
| 岩 · 凝聚 | 稍有增稠和承载感 | 柔软胶质组织及咀嚼反馈明显 | 有序晶质／弹性结构显著，可能妨碍内部释放 |

冰、岩的1／3／5沿用既定的平抑与凝聚描述锚点；其余五种基于已确认感官性质整理同尺度的**描述级参照**。这张表不代表G量到评级的计算系数已经确定，也不保证任何反应固定达到5。

## 3. 通常的阶段分布

| 基调 | 入口 | 中段 | 回味 |
| --- | --- | --- | --- |
| 火 | 可能率先出现灼感峰值 | 随时间回落 | 余感减弱 |
| 水 | 清冽、柔和 | 润泽舒展 | 平和收束 |
| 风 | 轻柔起始 | 传播并环绕口腔 | 短暂萦绕后消散 |
| 雷 | 可能骤发 | 脉冲、反复或细密活动 | 视具体反应而延续 |
| 草 | 逐渐变得饱满 | 持续发展充实 | 留下丰盈余韵 |
| 冰 | 降低初始峰值 | 减少段间起伏 | 延续平抑或封存 |
| 岩 | 感到组织承载 | 咀嚼、断裂、释放 | 结构余感逐渐结束 |

本表给出时间**倾向**，不是固定分数模板。反应产生的组织或持续状态可以改变阶段重心。


果实与果汁的原始材料事实使用当前自由元素`E_free[7]`、反应产物`Products[]`（都以G计量）；`M=ΣE_free+ΣProducts.amount`表示总物质量，**不能把元素物质量占比直接当作评级**。反应消耗过的自由元素不能再次全额计入感官；产物拥有独立阶段特征。

**尚无完整的 G → 1／3／5 计算公式。** 无可靠映射时保留该基调的阶段趋势、标签并显示「未定义」，不伪造数值。游戏内「尝一尝」直接提供所有已知信息，外部AI仅供玩家自行进行更细致的主观品评。
