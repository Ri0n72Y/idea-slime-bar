# 种植

MVP 中的种植只发生在预先设置的可种植地块上。玩家通过修整土地、播种、浇水、等待生长、选择性采叶、收获和清除植株完成一个完整种植循环。

水瓜是 MVP 的基础作物，也是第一株用于验证完整种植流程的植物。

## 地块

初始只有 1 块可种植地块。

地块在清除上一株植物后会回到“待修整”状态，修整完成后才能再次播种。

更多地块通过消耗积分解锁。MVP 中预计最多开放 6 块地。

## 播种

水瓜的种子就是完整成熟的水瓜果实。

玩家需要保留完整成熟果实作为下一轮播种材料。用于播种的果实会被消耗。

这一规则使成熟水瓜在 MVP 中至少存在三种去向：

- 留种
- 加工
- 提供给其他用途

## 生长阶段

水瓜共有四个生长阶段：

1. 幼苗
2. 拔高
3. 青果
4. 成熟

MVP 中四个阶段的基础时长比例暂定为 `1 : 1 : 1 : 1`。

具体总生长时间在数值平衡时继续调整。

## 水分

每块地维护自己的土壤含水状态。

MVP 使用 0–100 的可利用含水量表示土壤水分：

- 100：一次完整浇水后的适宜上限
- 50 以下：开始通过气泡或土壤颜色提示需要浇水
- 35 以下：植物暂停生长
- 0：土壤完全干燥

缺水不会导致植物死亡。补水后植物继续生长。

一次完整浇水将土壤补到 100。

土壤水分下降由两部分组成：

- 自然蒸发率
- 植物消耗率

MVP 中自然蒸发率使用常量，植物消耗率随生长阶段变化。

当前暂定参数为：

| 阶段 | 自然蒸发 | 植物消耗 | 总消耗 |
| --- | ---: | ---: | ---: |
| 幼苗 | 8/日 | 6/日 | 14/日 |
| 拔高 | 8/日 | 10/日 | 18/日 |
| 青果 | 8/日 | 14/日 | 22/日 |
| 成熟 | 8/日 | 12/日 | 20/日 |

这些数值只作为 MVP 的第一版游戏参数，不表示真实农业含水率。

## 叶片与果实

一株水瓜拥有 4 片叶和 4 个果实，可以视为四组对应的叶—果关系。

在青果阶段，玩家可以摘取叶片。此时获得：

> 厚实的水瓜大叶片

摘掉某片叶后，与该叶片对应的青果停止继续成熟。整株进入成熟阶段时，这颗果实仍保持青果状态，最终可以收获：

> 未成熟的水瓜青果

其他没有被摘叶的叶—果组不会受到影响，仍然可以正常成熟。

因此玩家可以在同一株水瓜上同时获得成熟果实和未成熟青果。

## 成熟叶片

如果叶片一直保留到成熟阶段，则不再获得“厚实的水瓜大叶片”，而是在植株清除时获得：

> 水瓜的大叶片

如果青果阶段没有摘叶，一株完整水瓜最终可以留下 4 片水瓜的大叶片。

## 收获

水瓜进入第四阶段后，正常生长的果实成熟，可以逐个摘取。

一株水瓜最多产生 4 个果实。青果阶段因摘叶而停止成熟的果实，在第四阶段仍以“未成熟的水瓜青果”状态存在并可收获。

水瓜完成这一轮结果后不会再次结果。

## 清除植株

果实收获完成后，玩家需要手动清除剩余植株。

清除时获得：

- 尚未提前摘取的水瓜大叶片
- 2 份水瓜茎

植株清除后，地块恢复到待修整状态。

## 劳动动作

MVP 当前动作时间如下：

| 对象 | 行动 | 总时长 | 占用史莱姆 | 中断重置 |
| --- | --- | ---: | --- | --- |
| 地块 | 修整土地 | 4 s | 是 | 否 |
| 地块 | 种下完整水瓜 | 3 s | 是 | 是 |
| 地块 | 浇水 | 3 s | 是 | 否 |
| 水瓜 | 摘取一片叶片 | 2 s | 是 | 是 |
| 水瓜 | 摘取一个果实 | 2.5 s | 是 | 是 |
| 水瓜 | 清除植株 | 5 s | 是 | 是 |

修整和浇水可以在中断后继续已完成的进度；播种、摘叶、摘果和清除植株在中断后重新开始读条。

## 地块解锁节奏

MVP 的地块扩张大致分为：

- 初始：1 块地
- 独立完成一次完整水瓜种植后：可以通过积分解锁第 2 块
- 开始接待客人并适应种植、加工和服务节奏后：可以解锁第 3 块
- 第 4、5、6 块主要作为后续积分消耗项，用于扩大生产规模

具体积分价格在完整 MVP 循环的计分频率确定后再设定。
