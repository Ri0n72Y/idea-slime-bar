# 种植

种植通过七元素养分供给、器官生长与玩家选择收获时机展开。当前水瓜玩法的权威数值见[数据与平衡](../../mvp/aquamelon-kitchen/02-data-and-balance.md)，器官与采摘身份见[生长与收获](../../mvp/aquamelon-kitchen/03-growth-and-harvest.md)。

## 土壤与养分

玩家放置土壤、播种，主动生成和收集七元素球。元素球会随模型时间衰减，收集时只有真实剩余量进入Soil。Soil及Sapling的Tree Reserve以七维V保存尚未转换的元素养分。

根系吸收随土壤实际供给、阶段上限及Tree Reserve状态变化；Sapling的生长预算再由当前Reserve、Tree Affinity与本次Δuh动态确定。预算只是本次可供分流的V额度，不是额外库存。

**V代表生长前的养分，G代表V完成生长转换后的元素量。** Tree/Bud取用的V按1:1转为G，叶及花果按自身生长规则转为G。**成熟水瓜只有G计量的自由元素和反应产物，没有V储备。**

## 树干、叶与果实

植物从Seed、Seedling发育到Sapling，不以整株定时“成熟”取代器官成长。进入Sapling时生成首枚Bud；树干每累积满100G并完成塑形周期，有空叶位且无Active Bud便在该事件创建一枚Bud。每模型日还有一次按当前叶片数量计算的出芽机会，但不能重复创建；当前最多三片叶和一个Active Bud，叶与芽占位合计不得超出三格。

各叶依次经历SmallLeaf、LargeLeaf并可附属FlowerBud、Flower、GreenFruit、MatureFruit。每片叶先取得本次树预算的30%；花苞、花及青果再从各自母叶所得V预算取得80%，成熟水瓜改取40%。成熟果仍挂树时由已纤维化母叶继续供给，其新G按该果实自身物质量M对应的线性富集倍率逐渐减速；采摘后停止。

## 收获

玩家根据实际器官状态采摘叶片、青果或熟果，形成独立世界材料，不能同时保留原活体和重复复制的物质账户。青果和成熟果的自由元素`E_free[7]`、反应产物`Products[]`始终以G计量。

当前千星2D Lua P0仅要求成熟水瓜一次加工成唯一一份水瓜汁，完整保留真实G物质及风味事实。更多田块、劳动读条、经营与自动化由后续玩法另行设计，不属于这套P0生长结算。
