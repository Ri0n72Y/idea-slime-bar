# 加工

加工使采摘的真实材料转换成成品。材料身份可以变化，但其中的元素物质量不能因此被重复复制。

## 水瓜当前加工路线

```text
MatureFruit（活体）
  → 采摘 → Aquamelon（独立世界材料）
  → 一键榨汁 → AquamelonJuice ×1
```

一份成熟水瓜直接转为唯一一份果汁，原果被消耗。果实的`E_free[7]`与所有`Products[]`完整转移到果汁，数值单位均为**G**；果实不存在独立V储备。加工不额外触发反应，不另生成需分账的瓜鬃、壳、肉或其他副产物。

果汁的物质事实用于生成自包含AI品尝提示词；完整合同见[一果一汁与AI品尝](../../mvp/aquamelon-kitchen/07-juice-and-ai-prompt.md)。

## 其他加工用途

瓜鬃、果壳、果肉膜、茎、叶等可以在未来加工中发挥不同作用。但加工设备、劳动时间及多产物G分配不属于当前P0；若扩展为多产物路线，必须先明确每个材料分得多少真实物质量，不得将完整`E_free+Products`复制给多个子材料。一般规则见[植物材料设计原则](../plants/material-design-principles.md)。
