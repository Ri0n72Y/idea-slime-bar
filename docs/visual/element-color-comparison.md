# 七元素图标 · 像素颜色对照

七张上传图标位于 `assets/elements/{Fire,Hydro,Anemo,Electro,Dendro,Cryo,Geo}.png`。打开同目录的 [`color-comparison.html`](../../assets/elements/color-comparison.html)，即可并排对比：

- 原始图标（透明背景）、对图标像素实时提取的主体色、此前使用的外部配色参考色；
- 对原图轮廓分别采用提取色和参考色着色的直观效果；
- 两色的 CIE Lab `ΔE76` 差异（较小表示较接近，并非某种官方匹配标准）。

**主体色提取规则：** 使用浏览器 Canvas 读取原 RGBA，默认仅保留 `alpha >= 150` 和 HSV 饱和度 `>= 20%` 的像素，然后寻找加权占优的 10° 色相分组及相邻两组，计算该色相簇的 RGB 分量加权中位数。这是用于比较的启发式算法，不是官方色号定义；可调整透明度/饱和度滑块并导出实测 JSON。纯白/灰度符号没有符合条件的彩色像素时，显示“无专属彩色”，不要将白色冒充元素颜色。

**颜色参考来源（非这七张 PNG 的实测结果）：** 上次整理的火 `#EC4923`、水 `#498FCC`、风 `#359697`、雷 `#6957C2`、草 `#66AD16`、冰 `#35AACC`、岩 `#CC9046`。这些色号来自独立的元素配色表参考，和图标源文件需分开辨认。
