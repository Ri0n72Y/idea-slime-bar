# 核果 Nutclear

核果（Nutclear）是一种富含油脂、能够富集能量的坚果类作物。核果先在地上发育，在一定阶段后进入土壤并长出更多根系，更高效地富集能量。成熟核果由外层土茧、硬壳、柔软果肉和中央坚硬的核组成。

地上发育期的核果更偏向食用，果肉肥厚、油脂丰富，并散发微弱的绿光。进入地下成熟后，果肉逐渐变薄，富集的能量则集中到中央硬核中。成熟果核经过进一步精炼后，可以作为高效的清洁能源。

## 形态

成熟核果由四层结构组成：

- 外层土茧
- 硬壳
- 柔软果肉
- 中央坚硬的核

成熟后的果比较薄、坚硬酥脆，吃起来更接近核桃。

## 生长

核果的叶片主要负责果实成长，根系主要负责能量富集。

### 地上发育

核果在地上发育时，外部只有一层硬皮，内部的果肉和果核还没有完全分离。

这一阶段的果肉肥厚，含有较多油脂，口感比较像栗子。核果此时已经能够富集一定的能量，但这些能量主要蕴含在果肉中，并不稳固，容易向外逸散，因此会散发出一点绿色的微光。

随着叶片继续向果实提供养分，果实会逐渐长大。

### 地下富集

核果发育到一定阶段后，会像花生一样进入土壤。

进入地下后，果实会长出更多根系，更高效地从周围环境中富集能量。外部逐渐形成土茧，原本的表皮也会增厚、变硬，形成硬壳。内部的果肉和果核开始逐渐分层。

富集的能量通过果肉不断集中到中央的硬核中。随着硬核逐渐增大，果肉会越来越薄，其中的油脂也会减少。

### 阻止入土

玩家可以通过物理方式阻止核果进入地下。

这种情况下，叶片仍然会继续为果实提供养分，但果实无法通过地下根系高效富集能量。养分会继续累积，使果实保持肉核不分、果肉肥厚并含有较多油脂的状态。

达到一定大小后，植株会主动将无法进入地下富集的果实抛弃。

## 用途

### 果肉

核果果肉可以食用。

地上发育或被阻止入土的核果果肉更加肥厚，油脂也更加丰富。地下成熟后的果肉较薄，吃起来更接近核桃。

其他食用和加工方式目前尚未具体设定。

### 果核

成熟果核经过进一步精炼后，可以作为高效的清洁能源。

具体的精炼方式和其他用途目前尚未确定。
