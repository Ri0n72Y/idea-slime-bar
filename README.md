# Liyue Kitchen: Grow It Yourself

The active MVP is a single-player 2D Web game built with React, TypeScript, Vite, and PixiJS 8. Its game-state and rules engine remain independent of the rendering layer. Browser interaction is verified with Playwright. Tauri v2 packaging is planned after the Web game becomes playable.

**The new Web MVP has not yet been implemented.** Work begins with [Web U1](https://github.com/Ri0n72Y/idea-slime-bar/issues/37).
